# FP4 权重冗余分析

对模型权重逐目标执行完整无损压缩插件，逐字节验证恢复，记录全部压缩成本。固定模型及路径配置模板见 [`.env.example`](.env.example)，服务器实际路径保存在不上传的`.env`。

跨对话接手、结果入口与规格交接方式见[协作说明](docs/协作说明.md)。仓库仅发布代码和结果摘要，不包含模型、构建产物或大型运行数据库。

## FP4 结果

每种技术一行，展示逐字节验证结果。Payload节省率为`1 − payload / 原始packed大小`；总节省率包含全部元数据，负值表示膨胀。
只计FP4权重本体，排除scale和其他dtype。Payload保留ANS重归一化输出/最终状态，以及前缀、索引、系数、纠错等编码数据流；独立码表/模型和布局另列元数据，总节省率完整计费。Payload列仅供诊断，分类见[开发说明](docs/开发说明.md#payload与元数据)。
抽样取 layer 0 中相邻专家0/1的完整w1/w2/w3，共6张矩阵；逐矩阵独立按1 MiB上限分块，覆盖全部行，不跨层或专家拼接。

## FP4 码字规律检测（R1–R4）

按[规格 001](docs/001-R1-R4规律检测.md)从零实现的统计测量（`diagnostics/`，不产生码流），样本为层 0/13/26/39 各 3 个路由专家的完整 w1/w2/w3，共 36 张矩阵；合成数据检查 T1–T6 全部通过后才读取模型。
36 张矩阵中位数（bit/权重）：R1 边缘偏斜 4 − H0 = 0.106；R2 块级离散度 0.161，scale 值作免费分组 0.127；R3 去掉块级差异后的顺序依赖约为 0；R4 只有 |v| 沿行相关（R² = 0.042，即 0.031 bit），且来自块级幅值聚集。
结果与读法见[检测摘要](experiments/r1-r4/summary.md)，格式依据见[格式事实](experiments/r1-r4/format.md)。

[规格 002](docs/002-账本核对.md)把 R1、零合并、scale 条件和 scale 流放在一起直接测量（检查 U1–U4 全部通过）。36 张矩阵中位数：节省 0.569 bit/权重（13.38%，含每矩阵码表），与 001 分项相加之差 < 1.3e-4。
再加块最大码 m_max 并扣除标签成本，净增 0.0047。按规格的相对 scale（减众数）共用码表会多花 0.020 bit/权重，原因是众数在两个主要 scale 取值间换边；补充测量按绝对 scale 共用只多 0.0015。
结果见[账本摘要](experiments/002-ledger/summary.md)。

[规格 003](docs/003-R5-R8规律检测.md)换成“段与段”的视角，检测精确重复（R6）、跨矩阵同位置（RX）、低秩（R5）、近似重复（R7）和稀疏（R8），合成检查全部通过（T2b、T4b 判据按完成状态所述调整）。
36 张矩阵与 75 对配对上：精确重复、块级近似重复/聚类和块级字典均不存在；低秩成分很弱（留出 R² 中位数约 0.002），扣除因子成本后净值全部为负。
唯一的严格正增量是同一专家 w1 与 w3 的同位置互信息（中位数 0.0011 bit/权重，L0 约 0.014）；按行看，w1、w3 的同一行号相关可达 ±0.85。
结果见[R5–R8 摘要](experiments/003-r5-r8/summary.md)。

[规格 004](docs/004-补缺与夯实.md)补测神经元级对应、同层专家共享结构、全层账本、实际往返编码和局部上下文混合，合成检查全部通过（TA1、TB2 按完成状态所述调整）。
账本在 40 个主干层上平均节省 0.571 bit/权重（与 0.569 差 0.002，MTP 层约 0.50），rANS 往返 3 张矩阵的 scale、合并零码字和数值均恢复一致（不保留负零位模式），码流比熵账多不到 0.0001 bit/权重。
同一神经元的 w1 行与 w3 行相关（严格净值中位数 0.013），专家级合计 40 层平均 0.0115 bit/权重，浅层最大；同层专家的共享子空间与行级字典很弱，严格净值全部为负；局部上下文混合的 0.033–0.045 几乎全部来自块组成，顺序与位置没有新结构。
结果见[补缺与夯实摘要](experiments/004-gaps/summary.md)。

[规格 005](docs/005-R9与生成模型.md)检验量化过程留下的痕迹（R9），并学习“块如何生成”和“数值是位置的函数”两类模型，另按规格自主探索了 10 个变体，合成检查全部通过。
每张矩阵较低的主要 scale 下，55% 的块没有 0.5、1.5 两档（块内独立时约 2%）；带网格级别标签的严格净值中位数 0.075 bit/权重，块类型混合模型（K = 32）0.073，二者逐张几乎相同，与 004 的“块组成”是同一种信息，不能相加。
探索中把块内最大幅值及其个数单独建模（VB1），在全层 258 张确认集上净值 0.081，每张都高于原设计；同层专家共用混合模型只多 0.0002。幅值的行列结构很弱：坐标网络净值全部为负（约 −0.084），只传行/列尺度档号的计数表在 12 张确认集上为 +0.0045。
结果见[R9 与生成模型摘要](experiments/005-r9/summary.md)。

## 使用

首次使用复制`.env.example`为`.env`并设置本地路径，然后在仓库根目录加载 `source .env`。查看已实现方法：`PYTHONPATH=src python3 -m fp4_redundancy methods`。
生成及执行完整矩阵抽样：`python3 scripts/run_fp4_sample.py plan`、`python3 scripts/run_fp4_sample.py run`。
连续码字分组抽样：`python3 scripts/run_grouped_sample.py run`；刷新结果：`python3 scripts/run_grouped_sample.py report`。
