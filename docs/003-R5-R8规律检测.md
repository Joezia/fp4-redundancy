# 003 R5–R8 规律检测

基于 spec 001、002 的结果（提交 `0a60ef5`）。本规格仍是统计测量：不产生码流，不实现压缩器。

## 0. 定位

001 检查了"一个码字与它附近的码字"的关系（R1–R4），结论是只有"同块共享一个 scale"这一层关系。002 把它记成账：4.25 → 约 3.68 bit/权重。

这类检测只能看到按距离组织的关系。本规格换一个视角：把矩阵切成一段一段（块、行、列、整张矩阵），问**一段数据与别的段之间有没有关系，不管它们在哪里**。

| 编号 | 规律 | 问的问题 |
| --- | --- | --- |
| R6 | 精确重复 | 有没有两段完全一样 |
| RX | 跨矩阵同位置 | 两张矩阵同一位置的码字是否相关（R7 最便宜的版本） |
| R5 | 低秩 | 是否所有行都是同样几个图案的混合 |
| R7 | 近似重复 | 有没有两段差不多一样；块是否聚成几类 |
| R8 | 稀疏 | 是否每段只用一个大字典里的少数几个图案 |

约束：

1. 沿用 001 的 36 张矩阵、格式事实，以及 `diagnostics/` 下已通过验证的代码；可在该目录新增模块。不 import `fp4_redundancy`，不读 `runs/` 和 001 之前的旧结果。
2. **第 7 节的检查全部通过之前，不在模型数据上运行。**
3. 只用 NumPy（哈希可用标准库 `hashlib`）。多进程时把每个进程的 BLAS 线程数设为 1。
4. 所有测量在合并零后的码字 `C'` 上做（002 已确认零的符号是纯随机位）。

## 1. 记号

沿用 001、002：`C'`、`s`、`m`、`E`、`B = 32`、`N`。新增：

| 记号 | 定义 |
| --- | --- |
| `v` | 码字的数值（不乘 scale） |
| `w` | 反量化权重 `v · 2^(E−127)` |
| 块向量 | 一个块的 32 个值，按块内位置 `p = 0..31` 排列 |
| 主 scale 组 | 该矩阵中 `E` 等于出现最多的那个值的全部块 |
| `H_E` | 该矩阵的 `H(C' \| E)`（002 M1），用作"每个码字值多少 bit" |

"域"指对哪种数值做计算：`v` 域或 `w` 域。

## 2. 样本与配对

矩阵：001 的 36 张（`experiments/r1-r4/samples.json`）。

配对（共 75 对，写入 `pairs.json`）：

| 组 | 定义 | 对数 | 用途 |
| --- | --- | ---: | --- |
| P1 | 同层、同角色、不同专家 | 36 | 专家之间是否相似 |
| P2 | 同一专家的 w1 与 w3（形状相同） | 12 | 同一专家两张矩阵是否相似 |
| P3 | 同角色、相邻抽样层（0↔13、13↔26、26↔39）、`samples.json` 中同序号的专家 | 27 | 对照：预期无关 |

每对记作（A, B），基线只作用在 B 上。

## 3. 打乱基线

固定种子。由数据导出的量（聚类、字典、最近邻）必须在打乱后的数据上重新计算。

| 记号 | 做法 | 保留 | 破坏 |
| --- | --- | --- | --- |
| S0 | 整张矩阵内置换全部码字 | 矩阵直方图 | 其余全部 |
| S0E | 在 `E` 相同的块所含的全部位置之间置换码字 | 每个 scale 组的直方图（即 002 已记账的结构） | 其余全部 |
| S2 | 每个块内部置换 | 每块的码字多重集 | 块内位置 |
| S3 | 整行为单位置换行序 | 每行内容、每列的多重集 | 行与行的对应 |
| S4 | 每个码字的符号位独立随机取值（零保持为零） | 每个位置的幅值 | 带符号的线性结构 |

读法：信号在 S2 下不变，说明它来自块的组成（已属 R2）；在 S2 下消失，说明它来自块内各位置的具体形状。S4 是 R5 的基线：幅值原地不动，只有符号被打散。

## 4. 显著性与换算

001 的教训：解析标准差只在真实值为 0 时成立。本规格统一用下面的规则。

- 互信息类：净值 = 真实值 − 基线均值（3 次重复）。显著 = 净值 > 5 × 解析标准差，**且** > 5 × 基线 3 次重复的标准差，**且** > 10⁻⁴ bit。
- 其他量：各测量项自己写明阈值。
- 留出条件熵：沿用 001 第 6 节的做法（一半计数、每格加 0.5，另一半算交叉熵，交换后取平均）。
- 标"严格"的数是留出条件熵或互信息，单位 bit/权重，可以与 002 的账直接相加。标"近似"的数来自方差比例的高斯换算 `−½·log₂(1 − R²)`，只作上限参考。

## 5. 测量项

### 5.1 R6 精确重复

- **R6.1 对齐的重复。** 单位取：块（32 个码字）、行、整张矩阵；另对 scale 取：行、整张矩阵。
  - 重复数 = 单位总数 − 不同内容的个数。范围：每张矩阵内部；36 张矩阵合并。
  - 另报：全零块的个数；只含不超过 2 种码字的块的个数（这两类重复是平凡的）。
  - 基线 S0、S2 各 1 次（块）。
  - 列出最多 20 个非平凡重复的例子：矩阵、行、块号、内容。
- **R6.2 不对齐的重复（矩阵内）。** 窗口只在同一行内取。对 k ∈ {8, 10, 12, 14, 16, 20, 24, 32, 48, 64}：
  - `dup(k)` = 长度为 k 的窗口总数 − 不同窗口的个数。它等于"从该位置起，能与别处匹配至少 k 个码字"的位置数。
  - 报告 `dup(k) / 窗口数`，以及 `K*` = 使 `dup(k) > 0` 的最大 k。
  - 基线：S2 各 k 1 次；S0 只做 k ≤ 16，1 次。
  - 可用 64 位哈希找候选；k ≥ 16 时报告出来的每个重复都要逐码字核对。
  - 净重复 = 真实 − S2。对 k ≥ 16 的净重复，列出最多 20 个例子（位置、长度、内容是否全零）。
  - 近似换算：`(dup(16) − S2 的 dup(16)) / N × H_E`，作为覆盖率上限。
- **R6.3 跨矩阵的重复。** 对 75 对，k ∈ {12, 16, 24, 32}：B 的窗口中也出现在 A 里的个数。基线：S2 作用于 B，1 次。

### 5.2 RX 跨矩阵同位置

对 75 对：

- **RX.1** `I(C'_A; C'_B)`、`I(m_A; m_B)`、`I(s_A; s_B)`，同一位置 (r, j) 配对。基线 S0、S2、S3（各 3 次，作用于 B）。
- **RX.2** 同一位置的相关系数：`v`、`|v|`、`w` 三种。基线同上。阈值 `5/√N`。
- **RX.3** `I(E_A; E_B)`，同一块位置配对。基线：整张 scale 矩阵内置换；按行置换。

`I(C'_A; C'_B)` 相对 S3 的净值是"严格"数：它是已知 A 后编码 B 能省的 bit/权重。

### 5.3 R5 低秩

对每张矩阵，在 `v` 域和 `w` 域各做一遍。矩阵先减去总均值。

- **R5.1 奇异值谱。** 完整 SVD。基线 S4（2 次），另对 `v` 域做 S0（1 次）。报告：
  - 归一化的奇异值（除以全部奇异值平方和的平方根），写入 CSV。
  - 前 k 层的能量份额，k ∈ {1, 2, 4, 8, 16, 32, 64, 128, 256}。
  - 有效秩 `exp(H(σ²/Σσ²))`（H 用自然对数）与稳定秩 `Σσ² / σ₁²`。
  - **超出层数**：奇异值大于 `1.02 × S4 最大奇异值（2 次平均）` 的层数；这些层的能量份额，减去 S4 同样多层的份额，记作超出能量。
- **R5.2 留出的低秩可预测性。** 样本内的低秩拟合对纯噪声也能"解释"一部分方差，所以用留出法：
  1. 把行随机分成两半 R₁、R₂，列随机分成两半 C₁、C₂（固定种子）。
  2. 取 `A = X[R₁, C₁]`，对 A 做 SVD 并只保留前 k 层，记其伪逆为 `A_k⁺`。
  3. 预测 `X̂[R₂, C₂] = X[R₂, C₁] · A_k⁺ · X[R₁, C₂]`。
  4. `R²(k) = 1 − ‖X[R₂, C₂] − X̂‖² / ‖X[R₂, C₂]‖²`。
  5. 四种"留出哪个象限"的选法各做一次，取平均。k ∈ {1, 2, 4, 8, 16, 32, 64, 128}。
  - 在真实数据和 S4（1 次）上做。纯噪声上 R² 应不大于 0。
  - 近似换算 `−½·log₂(1 − R²)`；因子成本 `k · (行数 + 列数) · 16 / N` bit/权重。
- **R5.3 换成码字的条件熵（严格）。** 仅当 R5.2 的最大 R² > 0.001 时执行，取 R² 最大的 k：
  - 每个元素都有一个留出预测值（来自它作为留出象限的那一次）。`w` 域的预测值除以该块的 scale，换回码值域。
  - 把预测值按八分位分成 8 档。报告留出的 `H(C' | E) − H(C' | E, 档)`。
  - 净值 = 该收益 − 因子成本。

### 5.4 R7 近似重复

- **R7.1 块的最近邻（汉明）。** 每张矩阵随机取 500 个查询块。对每个查询块，在同一矩阵、`E` 相同的全部其他块中，找相同位置数最多的块，记这个最大值 `best`。
  - 基线 S0E、S2 各 1 次（查询位置相同）。
  - 报告 `best` 的中位数、90%、99%、最大；`best` 超过"S0E 的 99% 分位 + 2"的查询比例。
  - 回本线 `m*`：使 `m · H_E > log₂(候选块数) + log₂ C(32, m)` 成立的最小 m。报告 `best ≥ m*` 的比例（真实与基线）。
- **R7.2 块的聚类。** 取主 scale 组，随机抽 100,000 块（不足则全取），前一半拟合、后一半评估。在 `v` 域和 `|v|` 域各做一遍。
  - k-means：初始原型为拟合集中随机 K 个块；迭代 20 轮（每块归到平方距离最近的原型，原型更新为类内均值，空类用随机块重新填）。K ∈ {2, 4, 8, 16, 32, 64, 128, 256}。
  - **失真比**：评估集上"每块到最近原型的平方距离之和" ÷ "每块到拟合集均值的平方距离之和"。
  - **严格收益**（K ≤ 64）：给全部抽样块标上最近原型的编号。在评估半区上算留出的两种收益：`H(C') − H(C' | 类)`，以及 `H(C') − H(C' | 类, 块内位置 p)`。各减去标签成本 `log₂K / 32`，得净值。
  - 基线 S0E、S2 各 2 次。独立数据上两种净值都应不大于 0。
- **R7.3 行与列的最近邻（相关系数）。** 每行减均值并归一化后，算行与行的相关系数矩阵；对每一行记它与其他行的最大绝对相关 `maxcorr`。列同理。`v` 域和 `w` 域各做一遍。
  - 范围：每张矩阵内部；75 对（A 的行对 B 的行，A 的列对 B 的列）。
  - 基线 S4（1 次）。
  - 报告 `maxcorr` 的中位数、99%、最大；`maxcorr > 1.2 × S4 的最大值` 的行（列）数；绝对相关 > 0.5 的行对（列对）数，并列出最多 20 个例子。

### 5.5 R8 稀疏

这一轮只判断是否存在，不换算成 bit。

- **R8.1 奇异向量的峰度。** 用 R5.1 的 SVD。对前 64 层，分别算左奇异向量（各行的系数）和右奇异向量（各列的系数）的峰度 `E[x⁴] / E[x²]²`（先减均值）。基线：S4 的同一量。
  - 报告中位数、最大；峰度 > 2 × S4 前 64 层最大峰度的层数，左、右分开。
- **R8.2 块级字典学习。** 数据同 R7.2 的 `v` 域（主 scale 组，一半拟合、一半评估），不减均值。
  1. 字典 64 个原子，初始为拟合集中随机 64 个块，各自归一化为单位长度。
  2. 迭代 15 轮：
     - 稀疏编码：每块用正交匹配追踪选 2 个原子（每次选与当前残差内积绝对值最大的原子，然后对已选原子重新做最小二乘）。
     - 字典更新：`D = (CᵀC + 10⁻⁶·I)⁻¹ CᵀX`，C 为系数矩阵；再把每个原子归一化；长度为 0 的原子用随机块重新填。
  3. 评估集上用 s ∈ {1, 2, 3} 个原子重建，`R²_dict(s) = 1 − ‖X − X̂‖² / ‖X‖²`。
  4. 对照：拟合集 `XᵀX` 的前 s 个特征向量做投影，得 `R²_pca(s)`；另报这 32 个特征值。
  - 基线 S0E、S2 各 2 次。
  - 字典对独立数据也能解释相当一部分方差，所以只看 `R²_dict(s)` 真实值 − S0E。显著 = 该差 > 0.01 且 > 5 × S0E 两次之差的绝对值。

## 6. 读法

| 观察 | 含义 |
| --- | --- |
| R6.1 有非平凡的块/行重复，或 R6.2 在 k ≥ 16 有净重复 | 存在精确重复（R6） |
| R6 的重复全部是全零或近似常数的窗口，且 S2 下仍在 | 属于块的组成（R2），不是 R6 |
| RX.1 相对 S3 净值显著（P1 或 P2） | 两张矩阵逐位置相关：参考式压缩的前提成立 |
| RX.1 相对 S0 显著、相对 S2/S3 不显著 | 只是块级或列级的共同幅值分布 |
| P3（对照）也显著 | 不是专家间的关系，检查实现或公共结构 |
| R5.1 有超出层，且 R5.2 的 R² > 0 | 存在低秩成分；能否回本看 R5.3 净值 |
| R5.1 有超出层，但 R5.2 的 R² ≤ 0 | 成分太弱，留出后无法预测 |
| R7.1 `best` 明显高于 S0E 和 S2 | 存在形状相似的块 |
| R7.2 的"类, p"净值 > 0 而"类"净值 ≤ 0 | 原型的具体形状有用（R7） |
| R7.2 的"类"净值 > 0 且 S2 下不变 | 仍是块的组成差异（R2 的剩余部分） |
| R7.3 有行/列超过基线 | 存在相似的神经元或输入维度 |
| R8.1 峰度超标，或 R8.2 真实值显著高于 S0E | 值得做更深入的稀疏分析 |
| R8.2 真实值高于 S0E，但与 S2 相同 | 来自块的组成，不是稀疏结构 |

## 7. 合成数据验证

不读模型。形状 1024 × 2048，B = 32，scale 取常数 127（此时 S0E 与 S0 相同，`w` 域与 `v` 域相同，只需做 `v` 域）。量化函数同 001：`m = searchsorted([0.25, 0.75, 1.25, 1.75, 2.5, 3.5, 5], |y|)`，`s = (y < 0)`，`C = 8s + m`。"独立底"指 `quant(1.68 · N(0, 1))`。每组数据都走与模型数据完全相同的代码路径。

单元检查：

| 编号 | 内容 |
| --- | --- |
| U1 | S0E 精确保留每个 scale 组的直方图（用 002 的 U3 构造，两种以上 scale） |
| U2 | S2 精确保留每块的多重集；S3 精确保留每行内容 |
| U3 | S4 精确保留每个位置的 `m`；`m = 0` 的位置在 `C'` 中保持为 0 |

构造与判据：

| 编号 | 构造 | 通过判据 |
| --- | --- | --- |
| T1 | 两张互相独立的独立底矩阵 | R6.1 块重复 = 0。R6.2：`dup(16)` = 0，`K*` ≤ 14。RX.1 相对 S0 不显著。R5.1 超出层数 = 0。R5.2 全部 k 的 R² < 10⁻⁴。R7.1：真实与 S0E 的 `best` 中位数相差 ≤ 1；`best ≥ 18` 的比例 = 0。R7.2：各 K 的失真比与 S0E 相差 < 0.005；全部严格净值 ≤ 0。R7.3 超过 1.2 × S4 最大值的行数 = 0。R8.1 超标层数 = 0。R8.2：`R²_dict(s)` 与 S0E 相差 < 0.01 |
| T2a | 独立底；随机选 100 个块，各复制到另一个随机的对齐块位置（源与目标互不重合） | R6.1 块重复 = 100；S2 下 = 0 |
| T2b | 独立底；取一段 200 个码字，复制到 50 个随机位置（都在行内，彼此及与源不重叠） | R6.2 的 `dup(64)` ∈ [6500, 6850]；`K*` = 64；S2 下 `dup(64)` = 0 |
| T3 | A 为独立底；B 的每个位置以 0.8 的概率等于 A，否则独立重抽 | 由 `C'` 的分布 p 算理论值：联合分布 `0.8·diag(p) + 0.2·p pᵀ` 的互信息。RX.1 相对误差 < 1%；S3 下不显著；S2 下的值 < 真实值的 1% |
| T4 | `y = 1.68 · (√0.1 · U Vᵀ / 2 + √0.9 · N(0,1))`，U 为 1024 × 4、V 为 2048 × 4 的独立标准正态；量化 | R5.1 超出层数 = 4。R5.2 的 R² 在 k = 4 处最大，且 ∈ [0.08, 0.11]。R5.3 收益 ÷ `−½·log₂(1 − R²)` ∈ [0.7, 1.1]。R8.1 超标层数 = 0 |
| T4b | 同 T4，但 U 的每个元素以 0.9 的概率置 0，其余除以 √0.1 | R5.1 超出层数 = 4。R8.1：左奇异向量超标 4 层，右奇异向量 0 层 |
| T5 | 16 个原型块（独立底）。每块以 0.3 的概率是"原型块"：随机选一个原型，每个位置以 0.3 的概率独立重抽；其余块为独立底 | R7.1：`best ≥ 18` 的比例 ≥ 0.2，S2 下 ≤ 0.01。R7.2（`v` 域，K = 32）："类, p"净值 > 0.15，"类"净值 ≤ 0，S2 下两者都 ≤ 0 |
| T5r | 标准正态矩阵；选 20 行，各改写为 `0.9 · 另一行 + √0.19 · N(0,1)`（源行互不相同且不在这 20 行中）；乘 1.68 后量化 | R7.3：超过 1.2 × S4 最大值的行数 = 40；这 20 对的相关系数中位数 ∈ [0.85, 0.92] |
| T6 | 48 个原子（32 维标准正态，归一化）。每块选 2 个不同原子，系数为独立标准正态，和乘以 4；`y = 1.68 · (√0.6 · 信号 + √0.4 · N(0,1))`；量化 | R8.2：`R²_dict(2)` 真实 − S0E > 0.2；S2 与 S0E 相差 < 0.03 |

任何一项不通过，先修正实现，不得放宽判据后继续。确有理由调整时，在完成状态中写明原因。

**偏离与解释**：
1. T2b 判据。规格期望 `dup(64)` ∈ [6500, 6850]，6850 = 50 × 137 只计完全落在拷贝内的窗口。越过拷贝边界的窗口在拷贝外的码字也可能相同：51 份拷贝之后紧跟的 1、2 个码字落在 15 个取值中，必然出现碰撞。这些是真实的重复，已逐码字核对。实测 6945 = 6850 + 95，`dup(k)` 的计算与规格定义一致，所以把判据改为可精确核对的形式：拷贝内的重复 = 6850，其余重复全部是两份拷贝同偏移的边界窗口，其他位置为 0；K* = 64 与 S2 = 0 两条不变。
2. R8.1 阈值与 T4b。S4 保留每个位置的幅值。T4b 中稀疏因子使约 10% 的行幅值变大，S4 的噪声奇异向量会集中到这些行上，峰度可到 344，于是“2 × S4 最大峰度”阈值为 688，而真实稀疏层的峰度只有 20–24，规格判据在这一构造下不可能满足（与实现无关）。改为同时报告两种计数：规格规则（2 × S4 前 64 层最大峰度）与调整规则（2 × S4 前 64 层峰度的中位数）；T4b 以调整规则判定（左 4、右 0），T1/T4 两种规则都要求为 0 且通过。模型数据两种计数都写入 `r8_sparse.csv` 和 `summary.md`；w 域 S4 也有峰度上千的向量，调整规则在 w 域的计数有一部分来自幅值分布。
3. 第 0 节限定只用 NumPy，第 8 节要求 PNG：计算只用 NumPy/hashlib，三张图用 Matplotlib 绘制（与 001、002 相同）。
