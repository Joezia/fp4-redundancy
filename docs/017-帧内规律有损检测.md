# 017 帧内规律有损检测（LLM.265 式）

## 目的

LLM.265（MICRO 2025）把权重矩阵当作图像，用 H.265 的帧内预测 + DCT + 量化做有损压缩，依据是“同一通道的值幅值相近”（条纹与平坦区）。本实验测 FP4（MXFP4）专家矩阵内部是否还有这种可被帧内预测 / 变换利用的规律。允许有损。

## 数据

每个模型取 24 个矩阵：DeepSeek 第 0、13、26、39 层，Kimi-K3 第 1、31、61、92 层；每层按固定种子随机取 2 个专家，各取 w1、w3、w2。按存储形状（不转置），读取方式与 016 相同。

## 两种视图

- **v 视图：** 只把码值 v（E2M1，不乘 scale）当图像，12 bit 亮度 = 2048 + 160·(2v)，15 个码值都精确可表示；块 scale 单独无损保存（零阶自适应码长计入码率）。重建 ŵ = v̂·2^(E−127)。
- **w 视图：** 把反量化值 w 线性映射到 12 bit 亮度（按矩阵最大 |w| 归一），直接编码；scale 的幅值结构也在图像里，帧内预测可以利用它。

## 方法与对照

- **HEVC 全帧内：** ffmpeg + libx265（conda-forge，x265 3.5），`keyint=1`，preset medium，单色 12 bit（Rext），QP ∈ {1, 6, 12, 18, 24, 30, 36, 42, 48} 与无损模式；每个矩阵切成 2×2 帧。码率 = 码流字节 + 边信息。
- **标量量化基线：** 不做预测和变换，对同一亮度信号做均匀量化（步长 Δ ∈ {1, 2, 4, …, 512}），码率为量化值的零阶自适应码长 + 边信息。
- **打乱对照：** 同一矩阵全部元素随机置换（v 视图连同各自的 scale 一起置换）后走同样流程。帧内规律存在时，真实矩阵在相同码率下的失真应明显低于打乱矩阵。
- **失真：** w 的归一化均方误差 NMSE = Σ(w − ŵ)² / Σw²（dB）。
- **DCT 能量集中度：** 对两种视图分别做 1×32、8×8、16×16、32×32 块的二维 DCT，计算编码增益（各频率系数方差的算术平均 / 几何平均）和方差最大的 10% 系数所占能量，真实与打乱对比。

## 合成检查

1. 平滑二维场（高斯滤波噪声）按 MXFP4 量化：DCT 编码增益应 > 1，HEVC 在相同码率下应明显优于打乱。
2. 独立同分布码值：真实与打乱应一致。

## 输出
