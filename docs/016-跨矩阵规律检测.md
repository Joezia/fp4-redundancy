# 016 跨矩阵规律检测（通宵离线实验）

## 目的

检测 FP4 专家矩阵之间是否存在类似视频帧之间的规律：同位置相同或相关、平移后相同或相关、重排（换位置）后相同或相关。
把 FP4 码字既当作数值，也当作 4 个比特（符号、2 位指数、1 位尾数）来比较。
用户要求：不使用已有结果侧面推测，全部重新实测；不只测相邻矩阵，要用全模型的全部矩阵；完整矩阵和局部都测；同位置和平移都测；能测多少测多少。

## 数据

- DeepSeek-V4.1-Flash：全部 47,232 个 MXFP4 专家矩阵（w1、w3 为 2304 × 5120，w2 为 5120 × 2304），共 5.57×10¹¹ 个码字，296 GB。
- Kimi-K3：全部 247,296 个矩阵（w1、w3 为 3072 × 3584，w2 为 3584 × 3072），共 2.72×10¹² 个码字，1.45 TB。
- 矩阵清单复用 015 的 `data/015/{deepseek,kimi}_matrices.json`（由 `redundancy.adapters.fp4.list_matrices` 生成）；读取用 `redundancy.adapters.fp4.FP4._read`，与 008/009/015 相同。
- 方向约定：“神经元维”是 w1、w3 的行和 w2 的列；“隐藏维”是 w1、w3 的列和 w2 的行。跨角色比较时把 w2 转置，使两边都是“神经元 × 隐藏维”。

## 比较的信号

| 名称 | 含义 | 相似度 |
|---|---|---|
| eq | 4 bit 码字整体相同 | 相同码字的比例（16 通道独热的内积） |
| bits | 4 个比特平面各自相同 | 比特一致的比例（4 个 ±1 平面的内积，即 1 − 汉明距离 / 比特数） |
| sign / e1 / e0 / m | 单个比特平面 | 该平面比特一致的比例 |
| v | 码值 E2M1（不乘 scale） | 皮尔逊相关或余弦 |
| absv | 码值的绝对值 | 皮尔逊相关 |
| w | 反量化值 v·2^(E−127) | 皮尔逊相关或余弦 |
| scale | 块 scale 的 E8M0 字节 | 同位置条件码长 |

## A 部分：成对完整矩阵与局部检测（分层抽样的矩阵对，两个模型）

矩阵对按类别从全模型均匀抽取（每类 30 对，固定种子）：

| 类别 | 说明 |
|---|---|
| A1 | 同一专家 w1 与 w3（已知同神经元相关，作阳性参照） |
| A2 | 同一专家 w1 与 w2ᵀ、w3 与 w2ᵀ |
| A3 | 同层不同专家、同角色 |
| A4 | 同层不同专家、不同角色 |
| A5 | 相邻层、同专家编号、同角色 |
| A6 | 相邻层、随机专家、同角色 |
| A7 | 相隔很远的层（层差 ≥ 层数的一半）、同角色 |
| A8 | 同一矩阵自身（只用于平移和局部搜索，排除零位移，测矩阵内部的平移重复） |

每对 (A, B) 计算以下各项，并对每一项都用“B 的全部元素随机打乱”做对照（无结构时的同一统计量）：

1. 同位置条件码长：用 Dirichlet-1/2 自适应码长（KT，与顺序无关的闭式），算 L(B) − L(B | A 同位置码字)，单位 bit/码字。
   - 另算以 B 自己的 scale 为条件的增量：L(B | E_B) − L(B | E_B, A 同位置码字)，即相对 R1+R2 的增量。
   - 逐比特平面：L(B 的第 k 比特) − L(B 的第 k 比特 | A 的同位置码字)。
   - scale：L(E_B) − L(E_B | E_A 同位置)。
2. 全局平移：对所有二维位移 (dy, dx)（|dy| < R，|dx| < W，用 FFT 的线性互相关）计算每个信号的重叠区相似度；记录最大值、所在位移以及与打乱对照的最大值。
   在 eq 最大的位移上重算第 1 项的条件码长（只用重叠区，非重叠区不带条件），并扣除位移本身的成本 log2((2R−1)(2W−1)) bit。
3. 局部块的运动搜索：从 B 中随机取 64 个 32×32 块和 16 个 128×128 块，每个块在 A 的所有位置（步长 1，二维）上搜索最相似的位置（eq 与 bits 两种信号，GPU 卷积）。
   记录每块的最大相同比例和位置，以及打乱块的对照；把“最大相同比例”换成证据比特 n·KL(â‖p₀) − log2(位置数)（p₀ 为两矩阵码字分布下的偶然相同率），>0 才算有超出偶然的匹配。
4. 通用压缩器（不需要知道规律形式）：zstd −19 --long=27 与 xz −9e，分别对 packed 字节（2 码字/字节）和展开字节（1 码字/字节，能找到奇数个码字的平移）计算 C(A)、C(B)、C(A‖B)，条件码长 C(B|A) = C(A‖B) − C(A)，以及 NCD；对照为 C(A_打乱‖B)。

## B 部分：全模型检测（模型中的每个矩阵都参与）

对每个模型完整读一遍（DeepSeek 全部 47,232 个矩阵；Kimi-K3 全部 247,296 个矩阵），一次读盘同时做 B1–B3。

### B1 精确重复（穷举，不抽样）

在全模型范围内找完全相同的单元，单元位置任意（即任意矩阵、任意行号或块号，等价于以单元为步长的任意平移和重排）：
- 整个矩阵（码字 + scale）；每一行的码字；每一行的 scale；每一列的码字；
- 每个 32 码字块（只看码字；码字 + 该块 scale）；每个 8 行 × 32 列的小块。
用 64 位哈希计数，哈希相同的组再读回原始字节逐字节核对。按“同一矩阵内 / 跨矩阵”分别计数，并算严格节省：
重复单元的独立码长（按所在矩阵的零阶分布）减去引用成本 log2(单元总数) + 每单元 1 bit 标志，只计正的部分。
内存限制：Kimi-K3 的 32 码字块有 8.5×10¹⁰ 个，只保留哈希最高 2 位为 0 的四分之一（哈希空间的均匀子集，重复对要么整体在内、要么整体不在），计数乘 4 外推并标明。

### B2 向量最近邻（每个查询对全模型全部向量穷举）

- 查询：从全模型均匀随机抽取神经元向量（w1 行、w3 行、w2 列）和隐藏维向量（w1、w3 列，w2 行）；另各取同样数量的“打乱查询”（查询向量内部元素打乱）作对照。
- 数据库：全模型中同长度的全部向量（DeepSeek 每种约 1.1×10⁸ 个）。GPU 上分块矩阵乘法，穷举，不用近似索引。
- 信号：w 与 v 的 |余弦|（神经元存在“w3 行与 w2 列同时变号”的对称，所以取绝对值），bits 的比特一致比例。
- 记录：每个查询的前 4 个最相似向量（排除自身），以及按类别（同矩阵其他向量、同专家其他角色、同层其他专家、其他层）的最大值。

### B3 局部块的全模型运动搜索（步长 1）

- 查询：从全模型随机抽取局部块，形状 1×64、8×8、16×16；另取同数量的打乱块作对照。
- 每个查询与全模型每个矩阵的每个位置（步长 1，二维）比较，信号为 bits（比特一致比例）和 v（余弦）。
- 记录每个查询的最大相似度、所在矩阵和位置（排除自身位置），并分“同矩阵 / 其他矩阵”。
- 判断：真实查询的最大值分布与打乱查询的最大值分布（同样的搜索规模下的极值）比较；并对最强匹配换算证据比特。

## C 部分：全模型联合的通用压缩

把一组矩阵按不同顺序拼成一条流，用 zstd −19 --long=31（2 GiB 窗口）整体压缩，与每个矩阵单独压缩之和比较；差值就是压缩器在跨矩阵范围找到的重复（任意偏移的精确匹配）。
顺序：(a) 层 → 专家 → 角色；(b) 角色 → 专家编号 → 层（相同专家编号跨层相邻）；(c) 只取同一角色。
对照：同样的拼接，但每个矩阵内部元素打乱（只剩码表共享的影响）。
范围：DeepSeek 的若干个完整层与按专家编号的跨层组；时间允许时扩大。

## 合成检查（先于真实数据运行，全部通过才开跑）

在合成的 FP4 矩阵（按真实码字分布独立抽样）中植入已知规律，检查每个检测器能检出、在无植入时与对照一致：
1. B = A 平移 (dy, dx) 后再随机改掉 30% 的码字 → A 部分第 1 项在零位移处无增益，第 2 项在正确位移处有增益。
2. 在 B 的随机位置植入 A 中某个 32×32 区域的拷贝（改掉 20%）→ 第 3 项找到正确位置。
3. 在数据库的另一个矩阵中植入某查询行的拷贝（改掉 30% 且整体变号）→ B2 找到它。
4. 植入完全相同的行、块与 8×32 小块 → B1 计数正确，跨矩阵 / 同矩阵分类正确。
5. 植入局部块拷贝（步长 1 的任意位置）→ B3 找到正确矩阵和位置。
6. 独立矩阵 → 各项与打乱对照无差异。

## 偏差与限制（实验前已知）

- B2、B3 的查询是随机抽样的，数据库是全模型穷举；查询数量按实测耗时确定，写入报告。
- Kimi-K3 的 B1 32 码字块只检查哈希空间的四分之一（见上）。
- 本实验只检测、不编码；即使检出规律，是否利用（会跨矩阵编码，与 AGENTS.md“按目标独立编码”冲突）由用户决定。
