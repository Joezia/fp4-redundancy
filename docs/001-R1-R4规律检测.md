# 001 R1–R4 规律检测（从零实现）

## 0. 定位

本规格要回答的问题是：**FP4 权重码字里是否存在 R1–R4 四种分布规律，各值多少 bit/权重。**

它是统计测量，不是压缩器：不产生码流，不实现任何压缩算法，不新增方法 id。

约束如下，与仓库其他文档冲突时以本节为准：

2. **不使用已有结果。** 不读取 `runs/`、`experiments/` 下的旧结果，不与旧结果对账，不以旧结果作为预期或通过判据。旧实现和旧结果的正确性未经查证。
3. **格式事实从第一手来源得出**（第 2 节）：safetensors 文件头、快照自带的 `config.json` 和参考推理代码。不沿用 `src/fp4_redundancy/checkpoint.py` 的结论。
4. **先验证估计量，再读模型数据。** 第 8 节的合成数据检查全部通过之前，不得在模型数据上运行测量。
5. 本规格授权：只读第 3 节列出的样本；在测量内部使用派生量（符号位、幅值、数值）和打乱。这些操作不写回数据，也不作为任何压缩方法的预处理。

## 1. 四种规律

| 编号 | 规律 | 含义 |
| --- | --- | --- |
| R1 | 边缘偏斜 | 单个码字的分布不均匀 |
| R2 | 分组异质性 | 码字分布随位置或分组变化（不同矩阵、行、列、块的分布不同） |
| R3 | 局部上下文依赖 | 已知邻近码字后，当前码字的条件分布变尖（任意形式的依赖） |
| R4 | 局部线性相关 | 把码字当数值看，邻居的线性组合能预测当前值 |

四者不可加。R2 会在成对统计里表现为"同组内的码字相关"，容易被误读成 R3；本规格用打乱基线区分它们（第 5 节）。

## 3. 样本

设文件头中共有 L 层。按规则选取，不沿用以前实验的样本：

- 层：`{0, ⌊(L−1)/3⌋, ⌊2(L−1)/3⌋, L−1}`。
- 专家：每层用 `numpy.random.default_rng(20261112 + 层号)` 从该层全部路由专家中无放回抽 3 个。
- 每个专家的全部 FP4 矩阵（预期 3 张）。

预期共 36 张矩阵。每张矩阵完整读入，以整张矩阵为统计单位，不分块、不截断。把实际选中的张量名、形状、码字数写入 `samples.json`。

## 4. 记号

每张矩阵解包为码字矩阵 `C[r, j] ∈ 0..15` 和 scale 矩阵 `E[r, j // B]`。

| 记号 | 定义 |
| --- | --- |
| `s`, `m` | 符号位 `C >> 3`，幅值索引 `C & 7` |
| `v` | 码字对应的数值（按 F2 的对应表，不乘 scale） |
| `b`, `p` | 块号 `j // B`，块内位置 `j % B` |
| `m_max` | 该块 B 个码字中最大的 `m` |
| `N` | 该矩阵的码字总数 |

## 5. 打乱基线

固定种子，每种打乱做 3 次独立重复。由数据导出的分组（`m_max`、能量档）必须在打乱后的数据上重新计算。

| 记号 | 做法 | 保留 | 破坏 |
| --- | --- | --- | --- |
| S0 | 整张矩阵内随机置换全部码字 | 矩阵直方图 | 其余全部 |
| S1 | 每行内部随机置换 | 每行的码字多重集 | 行内顺序、块归属 |
| S2 | 每个块内部随机置换 | 每块的码字多重集 | 块内顺序 |
| S3 | 整行为单位随机置换行的顺序 | 每行内容、每列的码字多重集 | 行与行的上下关系 |

读法：某项信号在 S2 下不变，说明它来自块级分布差异（R2）；在 S2 下消失，说明它来自顺序（R3/R4）。S3 对列方向起同样的作用。

## 6. 估计量的统一定义

- **熵与互信息**用计数表直接计算（plug-in），单位 bit。每个数值都同时报告样本数 `n`。
- **解析偏差**：独立数据上互信息的期望约为 `dof / (2 n ln2)`，标准差约为 `sqrt(2·dof) / (2 n ln2)`，其中 `dof = (Kx−1)(Ky−1)`，K 为实际出现的取值个数。每组样本很少时（如每块 32 个）此公式偏小，以打乱基线为准。
- **净值** = 真实值 − 对应打乱基线的均值。
- **显著**：互信息净值大于 5 倍解析标准差；自相关绝对值大于 `5/√n`；其他量的净值大于基线 3 次重复标准差的 5 倍且大于 10⁻⁴ bit。
- **留出条件熵**：偶数行的目标码字用于计数（每格加 0.5），在奇数行的目标码字上算交叉熵；交换后取平均。对照用的 H0 以同样方式留出计算。上下文取值来自数据本身，不受奇偶划分限制。
- 所有信息量报告为 bit/权重，同时给出占 4 bit 的百分比。

## 7. 测量项

### A. R1 边缘分布

- **A1** 每张矩阵：16 格直方图、H0、出现过的码字数 K。把 `4 − H0` 拆成两项：未用码字 `4 − log₂K`，已用码字内部的偏斜 `log₂K − H0`。
- **A2** 两个零（幅值索引 0，符号 0/1）各自的计数；合并两者的收益 `P(m=0) · H(s | m=0)`。
- **A3** 符号与幅值：`H(s)`、`H(m)`、`I(s; m)`。
- **A4** scale：直方图、H0(E)、取值范围、出现过的取值数。
- **A5** `m_max` 的 8 格直方图。
- **A6** 全样本合并后重复 A1。

### B. R2 分组异质性

- **B1 解码端已知的分组。** 计算 `I(C; G)`：
  - 跨矩阵（合并统计）：G 取矩阵、层、角色（如 w1/w2/w3）、专家。
  - 矩阵内：G 取行 `r`、列 `j`、块号 `b`、块内位置 `p`、奇偶 `p % 2`、scale 值 `E`。
  - 基线 S0；另列解析偏差和码表成本估计 `(K−1) · |G| · 12 / N` bit/权重。
- **B2 由数据导出的分组**（需要传标签）。G 取 `m_max`，以及能量档：块内 `|v|` 的均值按矩阵内分位数分成 2、4、8 档。报告 `I(C; G)`、标签成本 `H(G) / B`、可实现净收益 `I(C; G) − H(G) / B`。在 S0 上重复。独立数据上该净收益应不大于 0。
- **B3 块级离散度。** `I(C; 块id)`，基线 S0。净值是块级差异的总量指标，不含标签成本。
- **B4 自适应码长。** 逐块顺序处理 B 个码字，第 k 个码字的预测概率为 `(α · q(c) + 块内此前 c 的出现次数) / (α + k)`，q 为矩阵直方图，α ∈ {32, 128, 512}。累加 `−log₂` 得码长，报告 `H0 − 码长/N`。逐行版本同理，α ∈ {512, 2048, 8192}。在 S0 上重复。该项是不传标签时的可实现收益，不是检测指标。

### C. R3 局部上下文依赖

- **C1 沿行 MI–lag。** `I(C[r,j]; C[r,j+d])`，d = 1..96，分"同块对""跨块对""全部"三组。基线 S0、S1、S2。另对 d = 1..4 按起点列号 j 的奇偶拆成两组分别报告。
- **C2 沿列 MI–lag。** `I(C[r,j]; C[r+d,j])`，d = 1..64。基线 S0、S3。
- **C3 分量拆解。** d = 1..8，沿行和沿列分别计算 `I(s; s')`、`I(m; m')`、`I(s; m')`、`I(m; s')`。基线 S0。
- **C4 留出条件熵。** 报告 `H0 − H(C | 上下文)`，上下文依次取：左 1；左 1–2；左 1–3；上 1；上 1–2；左 1 + 上 1；左 1 + 上 1 + 左上。
  - 每个上下文在 S0 上重复（S0 的结果是学习成本，应为负）。
  - 只含"左"的上下文在 S2 上重复；含"上"的上下文在 S3 上重复。
  - 同时报告原始值和"真实 − S0"。

### D. R4 局部线性相关（数值域）

对 `v` 和 `|v|` 各做一遍，均先减去矩阵均值。不在乘了 scale 的权重上计算。

- **D1 自相关。** 沿行 d = 1..96（同块/跨块/全部），基线 S0、S2；沿列 d = 1..64，基线 S0、S3。另列 `5/√n`。
- **D2 功率谱与谱平坦度。** 逐行周期图，对全部行取平均，去掉零频；谱平坦度 = 几何平均 / 算术平均；报告 `½ · log₂(1 / 谱平坦度)`。沿列同样做一份。基线 S0。
- **D3 线性预测。** 特征为左侧 8 个邻居，加上一行的左上、上、右上，共 11 个。偶数行最小二乘拟合，奇数行计算 R²；交换后取平均。报告 R² 与 `−½ · log₂(1 − R²)`。基线 S0。
- **D4** 仅当 D3 的 R² > 0.001 时执行：把预测值按拟合半区的 8 个分位档作为上下文，按第 6 节的留出方式计算 `H0 − H(C | 档)`。

### S. scale 流（附带）

- **S1** scale 沿行、沿列的 MI–lag，d = 1..8，基线为整张 scale 矩阵内置换。
- **S2** `H(E | 左邻 scale)`、`H(E | 上邻 scale)`，留出估计。

3. 跨矩阵 B1（矩阵/层/角色/专家）的基线不能用 S0（矩阵内置换不改变矩阵直方图），改用 36 张矩阵全部码字合并后的随机置换（多元超几何抽样，3 次）。

   `summary.md` 另列“严格”计数（同时要求 |净值| > 5 倍打乱基线标准差），两种计数都保留。
5. 实现细节（规格未写明之处）：留出估计只用上下文完整的目标位置，H0 在同一目标集合上留出计算，平滑每格 +0.5、字母表 16；scale 的字母表取该矩阵出现过的取值。
