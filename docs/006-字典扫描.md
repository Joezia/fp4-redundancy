# 006 块级字典的大小扫描

基于 spec 003 的 R8.2（提交 `427ec6d`）。003 只测了"64 个原子、每块 2 个"这一种设定。本规格换不同的字典大小和每块原子数重测，回答：**结论是否依赖字典的设定。** 统计测量，不产生码流。

## 1. 约束

- 沿用 003 的 R8.2 实现（`diagnostics/` 下已验证的字典学习与正交匹配追踪）；不 import `fp4_redundancy`，不读 `runs/`。
- 第 4 节的检查通过之前，不在模型数据上运行。只用 NumPy。

## 2. 测量

样本：004 的探针样本 12 张。每张矩阵取主 scale 组，随机抽 100,000 块，前一半拟合、后一半评估，`v` 域，不减均值（与 003 相同）。

- 字典大小 K ∈ {16, 64, 256, 1024}；每块原子数 s ∈ {1, 2, 4}。共 12 种组合。
- 每种组合：用该 s 学字典（迭代 15 轮，初值为拟合集中随机 K 个块并归一化），在评估集上用同一个 s 重建，得 `R²(K, s)`。
- 基线：S0E、S2 各 1 次，整套流程重做。
- 回本线：`R²*(K, s) = 1 − 2^(−2·s·(log₂K + b) / 32)`，b 为每个系数的 bit 数，给出 b = 16 和 b = 8 两条。
- 对照：拟合集 `XᵀX` 的前 s 个特征向量做投影的 `R²_pca(s)`。

**主要结果**：12 种 (K, s) 组合上，真实与 S0E 之差的中位数都 ≤ 0.0006，单张最大 0.0085（L39.E61.w2，K = 64、s = 1；它与 S2 之差只有 −0.0002，来自块的组成）；真实 R² 离回本线（b = 8）至少差 0.16。结论不依赖字典设定。

**偏离与说明**：

1. **随机流**：块的抽样与 S0E、S2 打乱沿用 003 的随机流（以 003 的矩阵序号为种子），所以样本与 003 相同。(K = 64, s = 2) 的字典初值也用 003 的随机流，因此与 003 的 `R2_dict(2)` 逐张一致（差 ≤ 5×10⁻⁹）；其余组合的初值流另加 (K, s)。
2. **S0E、S2 各 1 次**，按规格；摘要中“真实 − S0E”的范围因此含单次打乱的波动（独立底上为 ±0.0006）。
3. **主 scale 组**：12 张中有的是 `E` = 120，有的是 121，记在 `sweep.csv` 的 `main_scale` 列。
4. 回本线按规格公式计算，`L = 32`。

**限制**：只覆盖 4 层、每层 1 个专家；只看主 scale 组的块；字典学习每个组合只用一组初值、15 轮，未检查其他初值是否给出更高的 R²（真实与打乱数据用的是同一流程，比较是对称的）。
