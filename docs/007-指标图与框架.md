# 007 冗余指标图与可移植的分析框架

基于 spec 001–006 的结论。本规格是阶段性节点，交付两样东西：

1. **十种规律各一张指标图**，统一格式，每张都带参照线，用 FP4 数据画出。
2. **一个固定的、可移植的分析框架**。以后换成别的数据（音频、图像等），只需写一个数据适配器，就能跑出同一套图。

统计测量，不产生码流。

## 1. 设计原则

- **三层分离。** 适配器（把某种数据变成统一的表示）→ 指标（只认统一表示，输出结果文件）→ 画图（只读结果文件）。任何一层都不得越过相邻的层。
- **指标层与画图层不含任何 FP4 专有的概念。** scale、E2M1、专家、w1/w2/w3 这些词只允许出现在 FP4 适配器和它的配置里。
- **每张图自带"有"与"无"的样例。** 每张图是三联：合成数据（无此规律）、合成数据（有此规律）、被测数据。读图的人先看到两种情况各长什么样，再看真实数据。
- **判定规则固定。** 每张图给出三选一的判定：无；存在但未过回本线；存在且过回本线。规则写在代码里，不靠人眼。

## 2. 代码结构

新建顶层目录 `redundancy/`（独立的包，不 import `fp4_redundancy`；只有 FP4 适配器可以调用 `diagnostics/` 里读取权重文件的代码）。只用 NumPy 与 Matplotlib。

| 模块 | 内容 |
| --- | --- |
| `dataset.py` | 第 3 节的统一表示 |
| `adapters/fp4.py` | FP4 权重 |

| `adapters/array_file.py` | 通用适配器：读任意 `.npy` 二维数组，选项见 3.3 |
| `baselines.py` | 打乱基线 |

用法固定为两条命令：

```bash

```

## 3. 统一的数据表示

### 3.1 字段

一个数据集是若干个"条目"，每个条目是一个二维数组（FP4：一张矩阵；图像：一个通道；音频：一段信号，可排成 1 行或按帧排成多行）。

| 字段 | 是否必需 | 含义 |
| --- | --- | --- |
| `symbols` | 必需 | 整数数组（行 × 列），取值 0..A−1，A ≤ 256 |
| `alphabet`、`raw_bits` | 必需 | 每个符号的名称；原始存储中每个符号占的 bit 数 |
| `values` | 可选 | 与 `symbols` 同形状的数值。符号没有数值含义时不给，R4、R5、R8 及 R7 的相关系数部分标为"不适用" |
| `groups` | 可选 | 若干个分组变量（名称 → 与数组同形状的整数），各自注明解码端是否已知；未知的要给出每个标签覆盖多少个符号 |
| `unit` | 可选 | 每个符号所属的局部单位编号及单位长度（FP4：块，长度 32）。用于"单位内打乱"和短段的 R7、R8 |
| `known` | 可选 | 已经记过账的分组（FP4：scale）。用于"已知分组内打乱" |
| `partner` | 可选 | 另一个同形状条目的 `values`，其各行是本条目各行的候选对象（FP4：同一专家的 w3 之于 w1） |
| `equivalences` | 可选 | R10 的等价存法清单：名称、涉及的符号或计数公式 |
| `process_checks` | 可选 | R9 的假设清单：每条给出"数什么"和"无约束时的预期分布怎么算" |

可选字段缺失时，依赖它的指标或基线自动退化（没有 `unit` 就只用整体打乱）或标为"不适用"，不得报错。

### 3.2 打乱基线

指标层只使用三种通用的打乱，由适配器提供的字段决定具体含义：

| 名称 | 做法 | FP4 中对应 |
| --- | --- | --- |
| 整体打乱 | 条内全部符号随机换位 | S0 |
| 已知分组内打乱 | 只在 `known` 相同的单位之间换符号 | S0E |
| 单位内打乱 | 每个 `unit` 内部换位 | S2 |

适配器可以为某个指标另外指定一种专用基线（FP4：R5 用"只打乱符号"，R7 的 `partner` 部分用"错位"）。

### 3.3 通用适配器的选项

`array_file` 读一个 `.npy`：整数数组直接作符号（超过 256 种取值时按配置取高位或等频分档）；浮点数组按配置分档成符号并保留原值作 `values`。可选：`unit_len`（按固定长度切单位）、`axis`（沿哪个方向算距离）。它不提供 `known`、`partner`、`equivalences`、`process_checks`。

## 4. 十张图

每张图是三联（合成-无、合成-有、被测数据），三个子图用同一套坐标和画法。被测数据有多个条目时，画各条目的中位数，并用浅色带表示最小到最大。

| 图 | 规律 | 横轴 / 纵轴 | 画什么 | 参照线 |
| --- | --- | --- | --- | --- |
| R1 | 各符号出现的概率不均匀 | 符号 / 概率 | 每种符号的占比（柱） | 均匀线 `1/A` |
| R2 | 不同分组的概率分布不同 | 符号 / 概率 | 净互信息最大的那个分组变量：每组一条分布曲线 | 各组重合即为无；整体分布画成灰线 |
| R3 | 与邻近符号有任意形式的关系 | 距离 d / 互信息 | 相距 d 的两个符号的互信息，d = 1..96 | 单位内打乱后的同一条曲线（没有 `unit` 时用整体打乱） |
| R4 | 与邻近数值有线性关系 | 距离 d / 相关系数 | `values` 的自相关，d = 1..96 | 噪声带 `±5/√n`；差分回本线 0.5 |
| R5 | 各行是少数图案的混合 | 层序号 / 能量份额（对数轴） | 奇异值平方占总和的比例，从大到小 | 随机谱（基线）；回本线 |
| R6 | 一段内容原样再现 | 长度 k / 重复比例（对数轴） | 长度 k 的窗口在别处出现过的比例，k ∈ {8,…,64} | 单位内打乱后的曲线；回本长度的竖线 |
| R7a | 一段与另一段相似（成对） | 相似度 / 段的比例 | 每段与最像的另一段的相似度的直方图。短段用相同位置数，长段用相关系数的绝对值 | 基线的直方图；回本线（竖线） |
| R7b | 一段与另一段相似（成群） | 原型个数 K / 失真比 | k-means 在留出段上的失真比，K ∈ {2,…,256} | 已知分组内打乱后的曲线；回本线 |
| R8 | 各段只用字典里少数原子 | 字典大小 K / 解释比例 | 每段用 s 个原子时的留出 R²，s ∈ {1, 2, 4} 各一条，K ∈ {16, 64, 256, 1024} | 已知分组内打乱后的曲线；回本线 |
| R9 | 产生过程禁止或偏好某些情况 | 由假设决定 | `process_checks` 中每条假设：实际分布（柱） | 无约束时的预期分布（线） |

- R10 不单独成图：在 R1 的图里把互相等价的符号用同一种底色标出，并输出一张小表（等价名称、等价存法的个数、折合 bit/符号）。
- R2 图下方列出全部分组变量的净互信息与各自的回本线。
- R7a 对每种段各画一张：有 `unit` 时画单位（短段）；始终画行（长段）；有 `partner` 时另画"与 partner 各行"的一张。
- 另外输出 `overview.png`（只取各图的"被测数据"子图，排成 2 × 5）和 `overview.md`（每种规律一行：pattern、指标、判定、关键数字）。

## 5. 回本线与判定

记 N 为条目的符号数，b 为每个参数的 bit 数（默认 16，可配置），`H` 为符号的零阶熵。高斯近似的公式只用于画线和筛选。

| 图 | 回本线 |
| --- | --- |
| R1 | 不需要；图下方给出 `raw_bits − H` |
| R2 | 互信息须大于码表成本 `(A−1)(G−1)·b / N`；分组未知时再加 `H(分组) / 每个标签覆盖的符号数` |
| R3 | 互信息须大于码表成本 `(A−1)·A·b / N` |
| R4 | 相邻相关系数 0.5（差分开始有收益）；图下方给出上限 `½·log₂(1/谱平坦度)` |
| R5 | 一层的份额须大于 `1 − 2^(−2·(行数+列数)·b / N)` |
| R6 | 重复长度须大于 `log₂N / H` |
| R7a 短段 | 相同位置数须不小于满足 `m·H > log₂(候选段数) + log₂C(L, m)` 的最小 m，L 为段长 |
| R7a 长段 | 相关系数须大于 `√(1 − 2^(−2·(log₂(段数) + b) / L))` |
| R7b | 失真比须小于 `2^(−2·log₂K / L)` |
| R8 | 解释比例须大于 `1 − 2^(−2·s·(log₂K + b) / L)` |

判定规则（对每张图的"被测数据"）：

- **无**：真实值没有超出基线。超出的标准是：与基线均值之差大于基线 3 次重复标准差的 5 倍，并且大于该图在配置中规定的最小幅度。
- **存在，未过回本线**：超出基线，但没有任何一点越过回本线。
- **存在，过回本线**：有点越过回本线。

R1 只有"存在 / 无"两档；R9 以"实际分布与预期分布的总变差距离大于 0.05"为存在。判定写入结果文件，并显示在图的右上角。

## 7. 验收

全部通过后才算完成。

1. **合成数据的判定正确。** 对第 6 节每一对数据运行全流程："无"的一侧判定必须是"无"，"有"的一侧判定必须是"存在"（R4、R5、R6、R7、R8 须为"过回本线"）。
2. **与已有结果一致。** 在 FP4 原样本上，新框架算出的下列量与 001–006 结果文件中的对应量逐张比较，差不得超过容差：

   | 量 | 来源 | 容差 |
   | --- | --- | --- |
   | 零阶熵 | 001 | 10⁻⁶ |
   | 以 scale 分组的互信息 | 002 | 10⁻⁴ |
   | 相邻符号的互信息（同单位）及单位内打乱后的值 | 001 | 10⁻⁴ |
   | `\|v\|` 的相邻自相关 | 001 | 10⁻³ |
   | 最强一层的能量份额及其基线 | 003 | 10⁻⁴ |
   | 最长重复长度 | 003 | 相同 |
   | 短段最近邻的中位数 | 003 | 相同 |
   | K = 64 的失真比 | 003 | 0.005 |
   | (K = 64, s = 2) 的解释比例 | 003、006 | 0.005 |
   | 每单位内没有奇数档的比例 | 005 | 10⁻⁴ |

3. **可移植。** 用 `array_file` 适配器跑两个临时生成的 `.npy`，全流程不报错并出齐图：
   - 256 × 512 的均匀随机 `uint8`：全部判定为"无"。
   - 256 × 512 的平滑数组（独立正态沿行累加后做滑动平均，再等频分成 64 档）：R4 判定为"存在，过回本线"。
   - 两者都没有 `known`、`partner` 等字段，相应的图标为"不适用"。
4. **层的隔离。** `indicators/`、`plot.py`、`baselines.py`、`breakeven.py` 的源码里不出现 FP4 专有的词（scale、E2M1、expert、w1、w2、w3、mtp）；`plot.py` 不 import 任何适配器或指标模块。写成一个自动测试。
5. **可复现。** 同一配置连跑两次，结果文件逐字节相同（随机数全部由配置里的种子决定）。

## 8. 图的样式

- 每个子图 4.2 × 3.2 英寸，三联横排；200 dpi；同时输出 PNG 与 PDF。文件名固定：`R1_distribution`、`R2_groups`、`R3_mi_distance`、`R4_autocorr`、`R5_spectrum`、`R6_repeats`、`R7a_neighbors_<段名>`、`R7b_clusters`、`R8_dictionary`、`R9_<假设名>`、`overview`。
- 颜色固定：被测或合成的真实值 `#0072B2`；基线 `#999999`；回本线 `#D55E00` 虚线；多条曲线依次用 `#0072B2`、`#E69F00`、`#009E73`、`#CC79A7`。不靠颜色单独区分含义：基线一律细线，回本线一律虚线并在线旁标注"break-even"。
- 每个子图：标题为"合成：无 / 合成：有 / 数据集名称"；右上角为判定；下方一行为关键数字（如 `H = 3.893 bit, saving = 0.106`）。
- 全部文字来自 `labels.json`，含中、英两套。系统里找得到中文字体时用中文，否则用英文，并在运行日志中说明用了哪一套。

## 9. FP4 的配置与输出

- 条目：001 的原样本 36 张。R8 只用探针样本 12 张（与 006 相同）。`partner`：原样本 12 个专家的 w1 配 w3。

超出的一项是随机基线的均值：两边各是 3 次独立的单位内打乱的平均（随机流不同），单次打乱的标准差约 5×10⁻⁵，两个 3 次均值之差的标准差约 4×10⁻⁵，10⁻⁴ 约为 2.4 倍标准差，36 张中有 1–2 张超出属于预期的波动；真实值本身与 001 相差 ≤ 5×10⁻⁸。没有改容差，也没有为此复刻 001 的随机流。

**FP4 的判定**（`overview.md`）：R2（scale 分组，净互信息 0.127）、R7a 行（中位数 max|ρ| 0.078，基线 0.051）、R7a partner（w1 与 w3 对应行 |ρ| 中位数 0.152，基线 0.010）为“存在，过回本线”；R5 为“存在，未过回本线”（最强层份额 0.0025，基线 0.0012，回本线 0.014）；R1、R9（两条假设）、R10 为“存在”；R3、R4、R6、R7a 短段、R7b、R8 为“无”。与 001–006 的结论一致。

**偏离与说明**：

1. **R8 的判定用 b = 8**（配置 `R8.b`），图上同时画 b = 16 的回本线。第 6 节指定的 003 T6（48 个原子、信号占 0.6）在 b = 16 下 12 种组合都越不过回本线（最接近的 (64, 1)：0.513 对 0.614），第 7.1 项要求它“过回本线”；在 b = 8 下 (64, 1) 为 0.513 对 0.455。规格允许配置 b，这里据此选 8，FP4 的结论在两种 b 下相同（离两条线都很远）。
2. **曲线类图的标准差**：判定规则用“基线 3 次重复标准差的 5 倍”。3 次重复的逐点标准差只有 2 个自由度，长曲线上总有个别点被严重低估：均匀随机数组在 R3 的 d = 23 处因此被判为存在（该点标准差 0.00023，曲线典型值 0.0018）。现在 R3–R6、R7b、R8 每点取“该点标准差”与“整条曲线标准差的中位数”中较大者，只会抬高门槛。多个条目时，对各条目的真实值、基线均值、标准差分别取中位数后再判定。
3. **“过回本线”** 取“某一点既超出基线又越过回本线”，避免基线本身已在线外时误判。R7a 的“超出基线”用段相似度的均值，“过回本线”用越过回本线的段所占比例（与基线比较）。
4. **等价符号**：适配器用 `equivalences` 声明的等价符号类（FP4：+0 与 −0）在比较内容的指标（R6、R7a 短段）上先合并，与 003 在合并零后的码字上测量一致；R1–R3 用原符号，与 001 一致。
5. **R6 的重复比例** 定义为 (窗口数 − 不同窗口数) / 窗口数，同 003；“最长重复长度”是 k 网格上有重复的最大 k（003 的 K*）。
6. **R7a partner** 比较第 i 行与 partner 的第 i 行（候选只有 1 个，回本线按 1 个候选算），基线把 partner 的行随机置换。R7a 行（长段）的基线为已知分组内打乱。
7. **R9 的第二条假设**（每块最大档）在第 6 节没有合成对照；另加一对：“无”为独立底，“有”为每单位按最大值缩放到 6 后量化（量化器按 amax 定 scale 的机制）。R9 的合成对照按假设的种类（`count_in_unit`、`max_rank_in_unit`）对应到被测数据的各条假设。
8. **R2 的层、角色**在一个条目内是常数，作为“条目级”分组在 36 张之间合并计算互信息，基线为在条目之间置换标签。R2 的“过回本线”用净互信息（减去打乱基线）与码表成本比较。
9. **R10** 的计数：等价符号类按数据中出现次数 × log₂(类大小) 计；神经元排列（2304! 种）与成对翻转符号（2²³⁰⁴ 种）按专家计，均匀摊到该专家的 3 张矩阵上。折合 0.117、0.00063、0.000065 bit/符号。
10. **R7b、R8 的样本**：取 `known` 中最常见的标签（FP4：主 scale）的单位，至多 100,000 个，一半拟合一半评估，同 003/006；R8 只在探针 12 张上运行（配置项 `R8.entries`，只作用于被测数据）。
11. **R4** 同时画 `values` 与 |`values`| 的自相关，两者都参与判定；基线为单位内打乱。
12. **一个数据集内字母表不同**时（通用适配器可能出现），R1、R2 按最长的字母表补零并在结果里注明。

**限制**：

- 判定依赖配置中的最小幅度（`min_amp*`），这些值按“合成‘无’不误报、合成‘有’能检出”设定，换数据时可能需要按数据规模调整。
- 回本线都是高斯近似，只用于画线和筛选，不是实际编码的成本。
- R7a 短段只取 500 个查询单位；R8、R7b 每个设定只用一组初值。
- FP4 只用原样本 36 张（R8 为 12 张），每层 3 个专家、4 层。
- 结果文件中保留了每张矩阵的数值（`entries`），中间数组不保留。
