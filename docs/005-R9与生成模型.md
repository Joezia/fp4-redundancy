# 005 R9 痕迹与"学习生成方式"的模型

基于 spec 001–004 的结果（提交 `772a828`）。本规格仍是统计测量，不产生码流。

## 0. 定位

R9 指"数据的产生过程留下的规律"。它没有通用的检测量，只能提出具体假设再检验。本规格做两类事：

| 部分 | 内容 | 假设的来源 |
| --- | --- | --- |
| A | 检查一个已观察到的痕迹：幅值 0.5、1.5 两档偏少 | 对量化过程的猜测 |
| B | 学一个"块是怎么生成的"的模型：每块先抽一个类型，再按类型独立抽 32 个码字 | 001–004 的结论：同块码字只通过"块的类型"相关，与顺序无关 |
| C | 学一个"数值是位置的函数"的模型：先测幅值的行列结构（线性），再训练一个小的坐标网络（非线性） | 此前的 R5 只测了带符号的值，幅值的行列结构没有测过 |
| 自主探索 | 在 B、C 的原设计之外，由实现方根据结果自行尝试其他模型结构（第 5 节） | 减少"推送结果、等待下一份规格"的往返 |

约束：

1. 沿用 001 的格式事实与 `diagnostics/` 下已验证的代码；可在该目录新增模块。不 import `fp4_redundancy`，不读 `runs/` 和 001 之前的旧结果。
2. **第 7 节的检查全部通过之前，不在模型数据上运行。**
3. 只用 NumPy 与标准库。若环境中已经装有 PyTorch，第 5 节的变体可以使用它，但不得安装新的依赖，并且要先用它重跑 TC1–TC4。
4. 全部测量在合并零后的码字 `C'` 上做。

## 2. A 部分：粗网格痕迹

- **A1 奇数档个数的分布。** 每张矩阵、每个 `E` 取值：`n_odd` 的直方图（0..32）。
  - 对照一（解析）：若块内码字独立，`n_odd` 服从二项分布 `Bin(32, q_E)`，`q_E` 为该 `E` 下奇数档的占比。
  - 对照二：S0E（1 次）上的同一直方图。
  - 报告：`n_odd = 0` 的块所占比例（真实、二项、S0E）；真实与二项分布的总变差距离。
- **A2 网格级别。** 每张矩阵、每个 `E` 取值：`g` 的分布（真实与 S0E）。
- **A3 带标签的严格值。** 留出的 `H(C' | E) − H(C' | E, g)`，减去标签成本 `H(g | E) / B`。留出方式沿用 001。
- **A4 候选量化规则对照。** 不读模型。用合成权重跑下面的候选组合，算出与 A1、A2 相同的统计量，和真实数据并排列出。只陈述哪一种候选最接近，不下结论。
  - 权重分布：标准正态、拉普拉斯、自由度 4 的 t 分布；每块再乘一个块级系数 `exp(τ·N(0,1))`，τ ∈ {0, 0.3}。形状 1024 × 2048。
  - 规则 F：`e = floor(log₂ amax) − 2`，除以 `2^e` 后就近舍入到 E2M1，超过 6 的取 6。
  - 规则 C：`e = ceil(log₂(amax / 6))`，就近舍入。
  - 规则 C+：规则 C 之后做规范化：只要块内全部码值都不超过 3，就把码值全部乘 2、`e` 减 1；重复到不能再做为止。
  - 并排的统计量：块内最大码值为 3、4、6 的比例；占比最高的两个 `E` 各自的奇数档占比；`n_odd = 0` 的块比例及其与二项值之比；幅值 0.5、1.0、1.5 三档个数的大小顺序。

## 3. B 部分：的潜在类别模型

**模型。** 对每个 `E` 取值分别建一个混合模型：一个块以概率 `π_z` 属于 K 个类型之一，然后 32 个码字各自独立地按该类型的分布 `θ_z`（15 个概率）抽取。K = 1 时它就是 002 的 `P(C' | E)`。

**码长。** 一个块的码长为 `−log₂ Σ_z π_z · Π_k θ_z(c_k)`，除以 32 得 bit/权重。这个值等于"边解码边更新对类型的后验、逐个预测码字"的总码长，所以不需要传标签。

**拟合。** EM 算法，输入是每块的 15 格直方图。
- E 步：`r_bz ∝ π_z · Π_c θ_z(c)^{n_bc}`。M 步：`π_z` 为 `r` 的均值；`θ_z ∝ Σ_b r_bz · n_b + 0.5`（只对该 `E` 下出现过的码字加 0.5）。
- 迭代 150 轮；3 组初值（按块内 `|v|` 均值的分位分组、同样分组后打乱类别对应、随机责任），取训练似然最大的一组。
- 某个 `E` 的拟合块数少于 `500 · K` 时，对它改用满足该条件的最大 K（最小为 1）。

测量项：

- **B1 每张矩阵。** K ∈ {1, 2, 4, 8, 16, 32}。偶数行的块拟合、奇数行的块评估，交换取平均。`收益(K) = 码长(1) − 码长(K)`。
  - 模型成本：`Σ_E K_E · 16 · 16 / N` bit/权重（每类 15 个概率加 1 个先验，各 16 bit）。净值 = 收益 − 模型成本。
  - 基线：S0E（1 次，K ∈ {2, 8, 32}）。
- **B2 学到的类型。** K = 4 和 8 时，用整张矩阵拟合，对每个 `E`、每个类型记录：先验、奇数档占比、零的占比、`|v|` 均值、最大幅值为 6 的概率。写入 CSV。
- **B3 模型能否共用。** 全层样本每层有 2 个专家。把"每层第 1 个专家"的全部矩阵合并拟合一个模型（按绝对 `E` 分别建混合，K ∈ {1, 4, 16, 32}），在"每层第 2 个专家"的矩阵上评估；交换后再做一次。
  - 报告：共用模型的码长；与同一张矩阵 B1 码长之差（共用的损失）；另做"按角色（w1/w2/w3）分别共用"的版本。`mtp` 层单独拟合、单列。
- **B4 与 004-D 的对照。** 探针样本 12 张上，把 B1 的 `收益(32)` 与 `d_probe.csv` 中的"块组成"部分并排列出。

## 4. C 部分：幅值的行列结构

- **C1 幅值的低秩（线性）。** 对原样本每张矩阵，取 `X = |v| − (该 E 下 |v| 的均值)`，即先扣掉 scale 已经解释的部分。
  - 做 003-R5.2 的留出法，k ∈ {1, 2, 4, 8, 16, 32, 64}。基线 S0E（1 次）。
  - 若最大 R² > 0.001：按 003-R5.3 换成严格收益，上下文为（`E`，预测值的 16 分位档）；因子成本 `k · (行数 + 列数) · 16 / N`。
  - **C1b**：对 scale 矩阵 `E`（减均值）做同样的留出法，k ∈ {1, 2, 4, 8, 16}；基线为整张 scale 矩阵内置换。若最大 R² > 0.001，报告留出的 `H(E) − H(E | 预测值的 8 分位档)`，单位 bit/scale，并换算成 bit/权重（除以 32）。
- **C2 坐标网络（非线性）。** 对探针样本每张矩阵训练一个网络，输入是位置，输出是该位置码字的概率分布。
  - 数据划分：全部位置随机分成训练 70%、验证 10%、测试 20%。
  - 嵌入：每行一个 8 维向量，每列一个 8 维向量。初值：把非训练位置置 0 后，对 `v − 均值` 和 `|v| − 均值` 各做 SVD，取前 4 层；行嵌入为左奇异向量乘奇异值的平方根，列嵌入同理；两组拼成 8 维；行、列嵌入各自除以自身全部元素的标准差。
  - 网络：输入为 [行嵌入, 列嵌入, 两者逐元素相乘, `E` 的独热]，两层 64 单元的 ReLU 隐层，输出 16 个 logit。输出层偏置初值为训练位置上 `C'` 分布的对数，输出层权重初值为标准差 0.01 的正态。
  - 训练：Adam（β = 0.9, 0.999），学习率从 0.002 按余弦降到 0，批大小 65536，20 轮；每步之后嵌入乘以 `(1 − 0.01 × 当前学习率)`。
  - 早停：每轮结束算验证集交叉熵，保留最好的一组参数；若从未好于基准，收益记 0。
  - 基准：训练位置上的 `P(C' | E)`（每格加 0.5）在测试位置上的交叉熵。`收益 = 基准 − 网络的测试交叉熵`。
  - 模型成本：`((行数 + 列数) · 8 + 网络参数个数) · 16 / N`。净值 = 收益 − 模型成本。
  - 基线：对 3 张矩阵（每层取第一张 w1，共 4 张中的前 3 张）做 S0E 后重跑。

## 5. 自主探索

第 2–4 节是**原设计**，必须按原样完成并单独报告。在此之外，实现方可以根据已经得到的结果，自行提出并测试 B、C 两部分的模型变体，不必等待新的规格。目的是找到在严格口径下净值更高的生成模型，同时把试过的一切都留下记录。

### 5.1 每个变体必须走的四步

1. **写明假设与动机。** 用一两句话说明这个变体假设数据是怎样生成的，以及是哪个已有结果提示了它。
2. **先过合成数据。** 在独立底上，净值不得大于 0.001；并且至少有一种与该假设对应的埋入结构能被恢复（可以复用第 7 节的构造，也可以自行构造，构造方法要记录）。不通过的变体不得用于模型数据，但要记入日志。
3. **在开发集上测严格净值。** 净值 = 留出交叉熵的下降 − 模型成本（每个参数 16 bit，除非该变体明确规定了更低的精度并说明理由）。
4. **记入日志。** 无论结果好坏，都写入 `variants.csv`。

### 5.2 开发集与确认集

反复试验后挑最好的结果，会使这个结果偏高。所以把矩阵分成两组：

| 部分 | 开发集（探索时使用） | 确认集（探索结束后只用一次） |
| --- | --- | --- |
| B | 探针样本 12 张 | 全层样本中其余的矩阵 |
| C | 探针样本 12 张 | 原样本中每层第 2 个专家的 3 张矩阵，共 12 张 |

- 探索期间不得在确认集上运行任何变体。
- 探索结束后，每部分选出开发集净值最高的至多 2 个变体，连同原设计，把结构和全部超参数冻结，在确认集上各运行一次，之后不再修改。
- `summary.md` 以确认集上的数为准；开发集上的数只作参考，并注明"探索中"。
- 超参数只能用训练部分和验证部分来选，不得用测试部分。

### 5.3 预算与停止

- B、C 各自最多 10 个变体；探索阶段的墙钟时间合计不超过 8 小时。
- 某一部分连续 3 个变体都没有把开发集上的最好净值提高 0.002 以上，就停止该部分的探索。
- 负结果同样是结果。没有找到更好的变体时，如实报告。

### 5.4 可以尝试的方向

以下只是建议，实现方可以提出清单以外的变体，但要写明动机。

B（块的生成模型）：

- 类型的分布跨 `E` 共用，只有先验随 `E` 变化（参数更少，检验类型是否与 scale 无关）。
- 用连续的块级幅值系数代替离散类型：每块一个系数，码字分布由它经过量化区间算出（参数只有几个）。
- 把 A 的网格级别作为类型的显式约束（某些类型只允许偶数档）。
- 类型的先验取决于同一行前一个块的类型后验，或取决于邻块的 `E`。
- 类型的先验取决于所在的行或列（与 C 的嵌入结合）。
- 更大的 K，或用验证部分自动选 K。

C（位置的函数）：

- 嵌入维数取 2、4、16；不同的初值与正则。
- 只预测幅值，符号按 1 bit 计（输出更小）。
- 列嵌入在同层专家之间共用，成本按专家数摊薄（用层内样本）。
- 输入加入 004-A 的神经元对应：另一张矩阵同一位置的码字，加上该神经元的相关方向，学习 w1 与 w3 之间的非线性关系。
- 网络输出的不是单个码字的分布，而是该位置所在块的类型先验（即"行列决定块的类型"，与 B 结合）。

### 5.5 不允许的事

- 改变基准（`P(C' | E)` 的留出交叉熵）或成本的算法。
- 使用解码端当时还没有的信息而不计成本。
- 用测试部分或确认集来挑选变体、调超参数。
- 从日志中删去失败或不理想的变体。
- 读取第 1 节以外的矩阵，产生码流，或安装新的依赖。

## 7. 合成数据验证

不读模型。形状 1024 × 2048，B = 32，scale 取常数 127，量化函数与"独立底"同 003。记 `p_n` 为独立底的 `C'` 分布；`p_e` 为把 `p_n` 中奇数档的概率置 0 后重新归一化的分布。

"理论收益"的算法（用于 TB2、TB3）：按真实的混合参数抽 40,000 个块，算 `平均[−log₂ Π_k p̄(c_k)] − 平均[−log₂ Σ_z w_z Π_k p_z(c_k)]`，再除以 32；`p̄` 为混合后的边缘分布。

| 编号 | 构造 | 通过判据 |
| --- | --- | --- |
| TA | 每块以 0.3 的概率按 `p_e` 抽 32 个码字，否则按 `p_n` | A1：`n_odd = 0` 的比例 ∈ [0.29, 0.31]，二项值 < 0.001。A3 净值 ∈ [0.13, 0.15] |
| TB1 | 独立底 | B1：K = 2..16 的收益 ∈ [−0.001, 0.0005] |
| TB2 | 001 的 T3（每块以 1/2 概率 σ = 1.2 或 2.2） | B1：K = 2 的收益与理论收益相差 < 2%；K = 16 的收益 ≥ K = 2 的收益 − 0.001 |
| TB3 | 同 TA | B1：K = 2 的收益与理论收益相差 < 3%。B2（K = 2）：有一个类型的奇数档占比 < 0.005，两个先验与 (0.7, 0.3) 各差 < 0.02 |
| TB4 | TB2 的数据做 S2 | 码长与 TB2 相差 < 10⁻⁹（模型只依赖块的直方图） |
| TB5 | TB2 拟合出的 K = 2 模型，任取 100 个块 | 逐个码字做后验更新并预测，32 个预测概率的乘积与混合边缘概率的相对误差 < 10⁻⁹ |
| TC1 | 独立底 | C1 最大 R² < 0.001。C2 收益 ∈ [0, 0.001] |
| TC2 | 003 的 T4（带符号的秩 4 成分，占 0.1） | C1 最大 R² < 0.005。C2 收益 ≥ 0.05 |
| TC3 | `z = U Vᵀ / 2`（U 为 1024 × 4、V 为 2048 × 4 的标准正态），`s = exp(0.5·z)` 并归一化到均方为 1，`y = 1.68 · s · N(0,1)`；量化 | 003-R5.2 对带符号 `v` 的最大 R² < 0.001。C1 最大 R² ≥ 0.2，严格收益 ≥ 0.15。C2 收益 ≥ 0.18 |
| TC4 | `s = exp(0.3·a_i) · exp(0.3·b_j)`（a、b 为标准正态）并归一化，`y = 1.68 · s · N(0,1)`；量化 | C1 严格收益 ≥ 0.14。C2 收益 ≥ 0.14 |

TC 各项中 C2 的批大小改为 16384（矩阵较小），其余设置不变。

任何一项不通过，先修正实现，不得放宽判据后继续。确有理由调整时，在完成状态中写明原因，并同时给出原判据下的数值。
