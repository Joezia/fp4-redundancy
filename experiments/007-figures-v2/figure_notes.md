# 图的说明：FP4 weights (36 matrices)

每张图一节：标题、坐标轴、画了什么、基线、回本线（每个参数 16 bit）、关键数字和判定。多条目时线和柱为各条目的中位数，浅色阴影或误差线为最小–最大。

判定规则：某点真实值与基线 3 次重复均值之差大于 5 倍标准差且大于最小幅度，即为“超出基线”；曲线类图每点的标准差取该点与整条曲线中位数中较大的一个；多条目时先对真实值、基线均值和标准差各取中位数。某点既超出基线、又越过回本线，即为“过回本线”。

## R1　Code probability distribution

文件：`figures/R1_distribution.png`、`.pdf`。
单联：FP4 weights (36 matrices)。

**坐标轴**

- 横轴：码字编号 c，按编码顺序 0–15，每个都标出刻度。
- 纵轴：该码字在条目中的占比（%）。

**画了什么**

- 蓝柱：36 个条目的中位数；黑色误差线：各条目的最小值–最大值。
- 灰色水平线：均匀分布 1/16（6.25%）。

**基线**：无打乱基线（打乱不改变直方图）。

**回本线**：不画回本线。判定为两档：原始位宽 − H 大于最小幅度 0.01 即为存在。

**关键数字**

- 零阶熵 H = 3.894 bit（中位数），原始 4 bit，可省 0.1059 bit/码字。
- 占比最高的三个编号：c = 10（10.2%），c = 2（10.2%），c = 12（8.48%）。

**判定**：存在。

## R2　Entropy reduction by grouping variable

文件：`figures/R2_groups.png`、`.pdf`。
单联：FP4 weights (36 matrices)。

**坐标轴**

- 横轴：分组变量 G。None 在最左（不分组），其余按柱高从高到低。
- 纵轴：相对 4 bit 原始存储的节省（bit/码字），从 0 开始。

**画了什么**

- 堆叠柱：下段（浅色）= 边缘偏斜 4 − H(C)，各柱相同；上段（深色）= 该变量的净互信息 I(C; G)，即真实互信息减去完全打乱基线的均值，负值显示为 0。
- 误差线（只在逐条目计算的变量上）：各条目净互信息的最小–最大值，画在下段中位数之上。跨条目合并计算的变量（只有一个合并值）不加误差线。

**基线**：完全打乱：条目内全部码字随机置换、标签不动，3 次重复；跨条目合并的变量在条目之间置换标签。

**回本线**：图中不画回本线。每个变量的成本 = (A − 1)(G − 1)·16 / N（码表），解码端没有的标签再加 H(标签) / 覆盖的码字数；数值见表。

**关键数字**

- 边缘偏斜 4 − H(C) = 0.1059 bit/码字（各柱下段，全部相同）。

| `block_max_level` | 不画 | 0.1167 | 0.06922 | 0.1301 | 0.0311 | 是 | 是 |
| `row` | Row | 0.002136 | 0.0009268 | 0.004594 | 0.0469 | 是 | 否 |

| `layer` | Layer | 0.0002816 | 跨条目合并 | — | 1.7e-06 | 否 | 否 |
| `position_in_block` | Position in block | 1.816e-05 | -4.056e-06 | 0.0001036 | 0.000631 | 否 | 否 |
| `role` | Role | -6.601e-05 | 跨条目合并 | — | 1.13e-06 | 否 | 否 |

- 净互信息为负、图中显示为 0 的变量：Role = -6.601e-05。
- 按配置不画的变量：`block_max_level`（数值见上表）。

## R3　Mutual information I(C_j ; C_{j+d})

文件：`figures/R3_mi_distance.png`、`.pdf`。
单联：FP4 weights (36 matrices)。

**坐标轴**

- 横轴：距离 d（同一行内相隔的位置数），1–96，每 16 一个刻度。
- 纵轴：互信息 I(C_j; C_{j+d})（bit），C_j 为一行中第 j 个码字。

**画了什么**

- 蓝线：全部码字对的互信息，36 个条目的中位数，浅色阴影为最小–最大。
- 灰线：基线（完全打乱（条目内全部码字随机置换））均值的中位数。
- 橙色虚线：回本线。灰色点线：d = 32，块长。

**基线**：完全打乱（条目内全部码字随机置换），3 次重复。

**回本线**：一张 A × A 码表（A = 16，每参数 16 bit）的成本 (A − 1)·A·16 / N = 0.000326 bit。

**关键数字**

- d = 1：实测 0.02621 bit，基线 1.331e-05 bit。
- 超出基线的距离：23 个（1–23）。
- 同一块内相邻对（d = 1）：实测 0.028 bit。
- 块内打乱基线下 d = 1 的基线值：0.02625 bit。
- 另算的基线「块内打乱（每个块内部随机置换）」（只存于结果文件，不画）下的判定：无。

**判定**：存在，过回本线。

> 相对完全打乱存在的依赖，来自同一块 32 个码字共享同一个 scale：块内打乱（保留每块的码字集合）后消失。它与 R2 中 scale 分组的收益是同一来源，二者不能相加。

## R4　Autocorrelation function ρ(d)

文件：`figures/R4_autocorr.png`、`.pdf`。
单联：FP4 weights (36 matrices)。

**坐标轴**

- 横轴：距离 d（同一行内相隔的位置数），每 16 一个刻度。
- 纵轴：自相关 ρ(d)。

**画了什么**

- 蓝线：带符号的数值 v；橙线：幅度 |v|。各为 36 个条目的中位数，浅色阴影为最小–最大。
- 两条灰线：两者的基线（完全打乱（条目内全部码字随机置换）），图例合为一项。
- 橙色虚线：回本线 ρ = 0.5。灰色点线：d = 32。

**基线**：完全打乱（条目内全部码字随机置换），3 次重复；相关系数用全局均值与方差。

**回本线**：|ρ(1)| ≥ 0.5 时差分预测开始有利（与参数位数无关）。另有谱平坦度给出的线性预测上限 ½·log2(1/平坦度) = 0.000174 bit。

**关键数字**

- ρ(1)：v = 0.000103（基线 1.2e-05），|v| = 0.105（基线 -9.28e-06）。
- 超出基线的距离：v 0 个，|v| 26 个。
- 另算的基线「块内打乱（每个块内部随机置换）」（只存于结果文件，不画）下的判定：无。

**判定**：存在，未过回本线。

> 相对完全打乱存在的相关（主要是 |v|），来自同一块共享同一个 scale：块内打乱后消失。它与 R2 中 scale 分组的收益是同一来源，二者不能相加。

## R5　Singular value spectrum

文件：`figures/R5_spectrum.png`、`.pdf`。
两联：(a) 合成数据（有此结构）；(b) FP4 weights (36 matrices)。两联纵轴范围相同，横轴范围相同。

**坐标轴**

- 横轴：奇异值序号 i（从大到小），1–64。
- 纵轴：归一化能量 σ_i² / Σ_j σ_j²（%，对数轴），σ_i 为去均值后数值矩阵的第 i 个奇异值。

**画了什么**

- 蓝线：实测（(b) 为条目中位数，浅色阴影为最小–最大）；灰线：基线；橙色虚线：各联自己的回本线。

**基线**：随机符号（数值乘以独立的随机 ±1，码字不变），3 次重复，两联相同。

**回本线**：一层 rank-1 的因子成本 (R + W)·16 / N 换算成能量份额：1 − 2^(−2(R + W)·16 / N)。两联矩阵大小不同，回本线不同。

**关键数字**

- (a) 最大层份额 8.34%（基线 0.322%），回本线 3.2%；超出基线的层：[1, 2, 3, 4]；判定：存在，过回本线。
- (a) 严格收益（k = 4，16 档）：毛收益 0.2315，因子成本 0.09375，净收益 0.1378 bit/码字。
- (b) 最大层份额 0.247%（基线 0.122%），回本线 1.39%；超出基线的层：[1, 2, 3, 4]；判定：存在，未过回本线。
- (b) 严格收益（k = 4，16 档）：毛收益 0.0008876，因子成本 0.04028，净收益 -0.03939 bit/码字（36 个条目中位数；净收益范围 -0.04038 … -0.02834）。
- 严格收益的做法：象限留出得到 rank-k 预测，按 16 分位分档作上下文，留出条件熵的下降为毛收益，因子成本 k(R + W)·16 / N；详见 r5_gain.json。

**判定**：存在，未过回本线。

## R6　Fraction of repeated length-k windows

文件：`figures/R6_repeats.png`、`.pdf`。
单联：FP4 weights (36 matrices)。

**坐标轴**

- 横轴：窗口长度 k（码字数），标出全部计算过的 k：8, 10, 12, 14, 16, 20, 24, 32, 48, 64（对数轴）。
- 纵轴：重复窗口占全部窗口的比例（%，对数轴）；最下方的刻度为 0，轴断裂记号以下的点表示 0。

**画了什么**

- 蓝线：实测（36 个条目中位数，浅色阴影为最小–最大）；灰线：基线。图中不画回本长度，横轴下限只按数据取。

**基线**：完全打乱（条目内全部码字随机置换），3 次重复。

**回本线**：复制一段要记位置，约 log2 N bit；长度 L* = log2 N / H 以上才划算，L* = 6.22。

**关键数字**

- 回本长度只是必要条件：长度 14 以上实测与基线都为 0（36 个条目的中位数），没有超出偶然水平的长重复（个别条目在 k = 14–20 仍有极少重复，最多 0.00032%；基线最多 2.8e-06%）；短长度处超出基线的部分见下方说明。
- 最长出现重复的 k（中位数）：12。
- 超出基线的 k：[8]。
- 另算的基线「块内打乱（每个块内部随机置换）」（只存于结果文件，不画）下的判定：无。

**判定**：存在，过回本线。

> 长度 8 处的超出来自同块共享同一个 scale（块内码字分布集中，短窗口更容易重复）：实测 1.41%，完全打乱 0.78%，块内打乱 1.42%，块内打乱后超出消失。它与 R2 中 scale 分组的收益是同一来源，不能相加；也不是“一段内容原样再现”意义上的长重复。

## R7a_partner　Correlation of corresponding W1 and W3 rows

文件：`figures/R7a_neighbors_partner.png`、`.pdf`。
单联：FP4 weights (12 W1–W3 pairs)。

**坐标轴**

- 横轴：|Correlation| between row i of W1 and row i of W3，0–1 分 100 格。
- 纵轴：行的比例（%，对数轴）。

**画了什么**

- 蓝柱：实测直方图（各条目归一化直方图的逐格中位数）；灰色阶梯线：基线；橙色竖虚线：回本线。

**基线**：对应行随机配对（把配对矩阵的行随机置换），3 次重复。

**回本线**：用另一行预测本行、只付 16 bit 系数：|ρ| > sqrt(1 − 2^(−2·16 / W))，W 为行长。

**关键数字**

- 合成“有”数据（图中未画，仅供核对）：中位数 0.493（基线 0.0147）；越过回本线的比例 100%（基线 0.13%）；回本线 0.104；判定：存在，过回本线。
- 中位数 0.152（基线 0.0105）；越过回本线的比例 78.8%（基线 0.145%）；回本线 0.0657；判定：存在，过回本线。

**判定**：存在，过回本线。

## R7b　k-means distortion vs. number of centroids K

文件：`figures/R7b_clusters.png`、`.pdf`。
单联：FP4 weights (36 matrices)。

**坐标轴**

- 横轴：原型（质心）个数 K = 2, 4, 8, 16, 32, 64, 128, 256（对数轴，全部标出）。
- 纵轴：留出失真比（%）= 留出块到最近原型的平方距离 / 到拟合半的均值的平方距离。

**画了什么**

- 蓝线：实测（条目中位数，浅色阴影为最小–最大）；灰线：基线；橙色虚线：回本线。

**基线**：同scale的块之间打乱，整条流程重复 3 次。

**回本线**：每个块只付 log2 K bit 原型编号：失真比 < 2^(−2·log2 K / L)，L 为块长。这条线不含参数位数（原型表的成本未计入），因此与 16 bit 的统一约定无关。

**关键数字**

- 合成“有”数据（图中未画，仅供核对）：K = 64：失真比 73.9%（基线 83.3%），回本线 77.1%；超出基线的 K：[2, 4, 8, 16, 32, 64, 128, 256]；判定：存在，过回本线。
- K = 64：失真比 83.1%（基线 83.1%），回本线 77.1%；超出基线的 K：[]；判定：无。

**判定**：无。

> 取样只取同一 scale 值（每张矩阵中出现最多的那个）的块，在这些块上“同 scale 的块之间打乱”与完全打乱等价，因此图例统一写 “Shuffled baseline”。

## R8　Dictionary learning with 4 atoms per block

文件：`figures/R8_dictionary.png`、`.pdf`。
单联：FP4 weights (12 matrices)。

**坐标轴**

- 横轴：字典大小 K（原子数）= 16, 64, 256, 1024（对数轴）。
- 纵轴：留出解释方差 R²（%，0–100%）。

**画了什么**

- 只画每块 4 个原子：蓝线为实测（12 个条目中位数，浅色阴影为最小–最大），灰线为基线，橙色虚线为回本线。

**基线**：同scale的块之间打乱，整条流程重复 3 次。

**回本线**：每块 s 个原子，各付 log2 K bit 编号和 16 bit 系数：R² > 1 − 2^(−2s(log2 K + 16) / L)。

**关键数字**

- K = 16：R² 34.7%（基线 34.6%），回本线 96.9%；K = 64：R² 57.1%（基线 57.1%），回本线 97.8%；K = 256：R² 70.1%（基线 70.1%），回本线 98.4%；K = 1024：R² 79.3%（基线 79.3%），回本线 98.9%。
- 被测数据的判定与回本线都按 b = 16 bit；判定：无（在任何 (K, s) 上都没有超出基线）。
- 合成数据的验收按合成配置中的单独设置 b = 8：合成“有”数据在 16 bit 下过不了回本线（007 已说明）。这一设置只用于合成数据，合成“有”的判定为「存在，过回本线」。

**判定**：无。

> 取样只取同一 scale 值（每张矩阵中出现最多的那个）的块，在这些块上“同 scale 的块之间打乱”与完全打乱等价，因此图例统一写 “Shuffled baseline”。
