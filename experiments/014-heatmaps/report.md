# 014：权重矩阵数值热力图

目的：直接看二维权重矩阵里数值大小的分布是否均匀，有没有跨行、跨列或二维局部的“一块一块”的结构。这里只做观察和少量统计，不做压缩，也不新增方法 id。

## 数据与做法

- **读取：** 快照与读取方式与 008（DeepSeek）、009（Kimi-K3）相同，用 `redundancy.adapters.fp4` 读取码值 C 和块 scale E。
- **代码：** [`heatmaps.py`](heatmaps.py) 画图并做统计，[`outliers.py`](outliers.py) 从统计结果里数出 RMS 偏离中位数的行和列，[`make_notes.py`](make_notes.py) 生成图注。
- **约束：** 没有使用 001 之前的结果、`runs/` 目录或 `fp4_redundancy` 的任何导入。所有数字都来自实际计算。
- **两种数值：**
  - FP4 码值：v ∈ {0, ±0.5, …, ±6}，不乘 scale。−0 画成 0。
  - 反量化值：w = v·2^(E−127)，可以在 BF16 中精确表示，图上写作 “dequantized (exact in BF16)”。
- **打乱对照：** 把全部元素用固定种子 20261123 随机置换，码值与反量化值用同一个置换。
- 各图的坐标轴、色标、截断值和基线见 [`figure_notes.md`](figure_notes.md)，统计的全部数值在 [`results/stats.json`](results/stats.json)。

### 与规格不同或需要说明的地方

- **Kimi-K3 的形状与规格写的不同。** 规格写的是“w2 是 5120 × 2304，w1、w3 是 2304 × 5120”，这只对 DeepSeek 成立。Kimi-K3 的 w1、w3 是 3072 × 3584，w2 是 3584 × 3072，形状读自 009 的 `matrices.json`，读取时也逐个断言过。行列含义的规则相同：w1、w3 的行是神经元，w2 的行是隐藏维。
- **全图（原始分辨率）只推送了 3 个矩阵。** 这是用户的要求，推送的是 DeepSeek L20.E86.w1、L20.E86.w2 和 Kimi-K3 L46.E484.w1。其余 15 个矩阵的全图留在本地 `data/014/full/<模型>/<矩阵>/`，共 376 MB，不在仓库里。
- **每张图只保留一种格式。** 这也是用户的要求：PNG 和 PDF 都生成后，留下较小的那个。结果是全图都是 PNG（4.9–6.3 MB；PDF 更大），其余图都是 PDF（矢量坐标轴加嵌入的图像）。
- **全图带标注边框。** 为了能在全图上标出行列含义，矩阵四周加了白边，用来写标题、行列含义和色标条。矩阵区域本身是一个元素一个像素。

## 每个矩阵看到的情况

下面只写能从图和统计中直接看出的内容。

- **CV：** 行 RMS（或列 RMS）的变异系数，括号里是打乱后的值。
- **“行 RMS 比”：** 某一行的 RMS 除以该矩阵所有行 RMS 的中位数，列同理。打乱后，所有行、列的这个比值都在 0.94–1.27 之间。
- **前提：** 预览图按 8×8 格取平均 |值|，在这种分辨率下，一两行宽的异常看不出来，只能从 RMS 曲线和数字看出。

### 所有矩阵共有的现象

- **码值在 32 列的块内一块一块。**
  - 同一行内相邻元素的 |v| 相关系数为 0.06–0.11（位移 d = 1）。随 d 线性下降，d = 16 时约为一半，d = 32 和 64 时降到 0（|相关| ≤ 0.0015）。打乱后，所有位移的 |相关| 都不超过 0.001。
  - 这正是“同一行、同一个 32 列块内的元素共用一个 scale”的结果：块内的 32 个码值整体偏大或偏小，跨块就不相关了。
  - 在码值的局部放大图里也能看到：每个 32 列块内，一行的 32 个元素明暗接近，所以块内呈现横向短条纹，块与块之间明暗不同。打乱后这种条纹消失。
- **反量化值没有这种块内结构。** |w| 的跨列相关在 d = 1 到 64 之间基本不变，不随 d 衰减。这说明剩下的相关性来自整行（或整列）的幅值差异，而不是 32 列的块。
- **预览图（8×8 格平均）和打乱版在大多数矩阵上看不出差别。** 例外是 Kimi-K3 L1 和 DeepSeek L39.E320.w2，下面分别说明。
- **没有看到二维局部的块状区域。** 也就是说，没有一片同时跨多行、多列、明显比周围亮或暗的区域。看到的结构都是整行或整列，即一维的条带。

### 小结

- **一维条带：** 看到的结构都是整行或整列的幅值差异，而且都在“神经元”这一维上（w1、w3 的行，w2 的列）。只有 DeepSeek L0、L39 在“隐藏维”这一维上有少数几个异常的列，在 w2 里则是对应的行。
- **同一神经元在三个矩阵中一致：** 同一个专家的 w1、w3、w2 中，异常的神经元经常是同一个。例如 Kimi-K3 L1 的 280 个低幅值神经元，以及 DeepSeek L0 的神经元 1201、L20 的 2089、Kimi-K3 L46 的 712 和 1229、L92 的 2805。
- **强弱差别：**
  - 最强的是 Kimi-K3 第 1 层：约 9% 的神经元幅值只有中位数的几十分之一。
  - 其次是 DeepSeek 第 39 层：w2 列 CV 0.11，隐藏维 529 的输入权重几乎为 0。
  - Kimi-K3 第 46、92 层最均匀，反量化值的 CV 只有打乱值的 2–4 倍。
- **块状结构：** 32 列块内的“一块一块”结构只在码值中出现，乘上 scale 以后消失。
- **二维局部：** 没有看到跨多行多列的块状区域。

## 补充：全样本的神经元幅值统计（用户要求）

**目的：** 回答“这种整行、整列的幅值差异是每层每个矩阵都有，还是只有个别矩阵才有”，为“w2 能否按神经元分上下文多压缩一点”做准备。

**做法：**
- **代码：** [`fullsample.py`](fullsample.py)，不画图，只算统计。
- **样本：** 与 008 完全相同的 DeepSeek 516 个矩阵（B 计划前 172 个专家；运行前核对过清单），以及与 009 完全相同的 Kimi-K3 552 个矩阵（`plan_552.json`，184 个专家）。
- **每个矩阵算什么：** 码值和反量化值“神经元维”与“隐藏维”的 RMS 变异系数，真实值与打乱值（种子 20261123）并列。神经元维是 w1、w3 的行和 w2 的列。
- **还数了什么：** 每个矩阵中 RMS 低于中位数一半、或高于 1.5 倍的神经元个数，以及同一专家 w1、w3、w2 中低幅值神经元的重合数。
- **结果文件：** 逐矩阵的值在 `results/fullsample_{deepseek,kimi}_items.jsonl`，汇总在 `results/fullsample_summary.json`。

**核对：** 结果在 014 的 18 个矩阵上与上文逐位相同（例如 Kimi L1.E236 三个矩阵的神经元变异系数 0.2910 / 0.2898 / 0.2972，以及 280 个三者共同的低幅值神经元）。

### 看到的情况

- **普遍存在，但绝大多数很弱。** 几乎每个矩阵的神经元维都比打乱基线不均匀，但变异系数的中位数只有 0.03–0.05，也就是各神经元的 RMS 相差几个百分点。隐藏维基本没有结构（比值中位数 1.02–1.19）。
- **Kimi-K3 有 107 个矩阵比随机排列还均匀。** 这些矩阵的神经元维变异系数小于打乱值，其中 w2 有 31 个，集中在第 12–21 层和第 56–85 层。DeepSeek 没有这种矩阵。
- **强的只有少数专家，而且集中在少数层。**
  - **DeepSeek 第 41、42 层的 3 个专家（L41.E99、L42.E8、L42.E62）：** 少数神经元比中位数大几十倍（最大 34–59 倍），w2 的列变异系数达到 1.5–2.3。这与 013 中 R5（低秩）唯一打开的几个矩阵是同一批。其余 DeepSeek w2 中，比值 ≥ 10 的只有 L42.E58、L36.E341、L39.E320、L39.E114，变异系数 0.11–0.16。
  - **Kimi-K3 有 23 个专家存在三个矩阵共同的低幅值（接近 0）神经元。** 最多的是 L1.E236（280 个）、L4.E895（275）、L1.E677（226）、L24.E38（167），其次是第 2–6、15 层的若干专家（33–62 个）。这些专家的 w2 列变异系数为 0.13–0.30。按层看，比值 ≥ 10 的 w2 只出现在第 1–4、6、24 层。
- **对 w2 而言，这些差异都留在码值上。** w2 码值的列变异系数与反量化值接近：例如 DeepSeek 中位数 0.030 对 0.037，Kimi-K3 L1.E236 为 0.292 对 0.297。原因是 scale 块沿行划分，不能吸收单个神经元的幅值。但 DeepSeek 第 41–42 层那 3 个专家例外，码值保留的比例较低：L42.E8、L42.E62 约一半（1.07 对 2.28、1.08 对 2.16），L41.E99 约 87%（1.32 对 1.52）。
- **对压缩的含义（推断，未实测）：** 在 w2 上按神经元（列）给上下文，只在上面这些少数专家上有明显的可利用空间：DeepSeek 约 3–7 个、Kimi-K3 约 10–20 个，占样本的 2–10%。其余 w2 的码值列变异系数只有 0.03 左右，能省多少要实测才知道，预计很小。
