# 010 补充：变换全集实验（TX）

规格见 [docs/010-变换全集实验.md](../../docs/010-变换全集实验.md)。代码在 `tx/`，结果在 `results/tx/`，用时记录在 `results/tx/timing.md`。010、011 的已有结果没有改动。

## 阶段 0：基础设施

### 数据

- **主样本：** 010 的 48 个矩阵。训练/选参集为每层前两个专家（24 个矩阵），测试集为每层后两个专家（24 个，即 011 的 T1）。泛化检查用 011 的 T2（24 个）。
- **跨专家样本**（阶段 2 用）：第 0、13、26、39 层，每层用固定种子（`default_rng([20261119, 30, 层])`）从主样本以外的专家中取 16 个；前 8 个选参，后 8 个报告。

### 两种视图（`tx/txcore.py`）

- **码值视图：** R10（±0 合并）之后的 15 个符号。
- **数值视图：**
  - 块内等级 L：E2M1 值乘 2，取值为 −12…12 的整数。
  - 跨块对齐值 X：L × 2^(本块 scale 指数 − 矩阵最小指数)。实测最大绝对值为 3072，用 int64 存储，不会溢出。
- **往返检查：** 码值 → L → 码值、X → L 两条路径，在全部 72 个矩阵（训练、测试、T2）上逐位一致。

### 两个评价编码器

两个编码器都用自适应计数的闭式码长，可按顺序解码，不生成实际码流。

- **C0（零阶）：** 不用上下文。
  - 符号数据：自适应多元分布，每个符号先验计数为 1/2。
  - 整数数据：拆成位长类别（0 表示零）、符号位、尾数位。符号位以类别为上下文；尾数前 3 位以类别、位置和已出现的高位为上下文。这与 008 中音频、图像链（`increment.eg_bits`）的二值化方式相同。
- **C1（上下文）：** 在 C0 的基础上加入两个因果邻居。
  - 二维数据：左邻和上邻。
  - 一维序列：前两个值。
  - 整数数据用邻居的位长类别作上下文；符号位另加邻居的符号；尾数前 3 位另加邻居类别。符号数据直接用两个邻居的符号作上下文。
- **合成数据检查**（`results/tx/synthetic_stage0.json`，全部通过）：
  - 独立同分布的符号和整数：C0 与熵之差小于 0.01 bit/值。
  - 以 0.8 的概率复制左邻的符号：C1 为 1.126 bit/值，理论条件熵为 1.100。
  - 二维平滑尺度场上的整数：C1 比 C0 少 0.31 bit/值。

### 参考基准（实测，`results/tx/reference.json`）

参考基准是 008 链式模型加上 011 的 R9c（奇数等级个数、非零个数、最大等级三项计数上下文，每矩阵 1 个开关位），总码长包括 scale 流。

| | T1（测试集） | T2 |
|---|---:|---:|
| 008 链式总码长 | 3.65638 | 3.67437 |
| R9c 再省 | 0.05076 | 0.05313 |
| **参考基准总码长** | **3.60562** | **3.62124** |
| 其中 scale 流 | 0.03078 | 0.02793 |
| 其中码值部分 | 3.57483 | 3.59332 |

单位都是 bit/权重。T1 码值部分为 3.6255 − 0.0508 = 3.5748，与规格给的参考值一致。

### 原始数据的 C0、C1 码长（测试集，bit/权重，不含 scale 流）

| 视图 | C0 | C1 |
|---|---:|---:|
| 码值，二维 | 3.7750 | 3.7507 |
| 码值，按行一维 | 3.7750 | 3.7280 |
| 块内等级 L，二维 | 3.7750 | 3.7557 |
| 块内等级 L，按行一维 | 3.7750 | 3.7394 |
| 跨块对齐值 X，二维 | 3.7308 | 3.7181 |

- C1 比参考基准的码值部分多 0.15–0.18 bit/权重。因此用 C0、C1 编码的变换方案，净收益几乎必然为负。这两个编码器的作用是衡量变换本身让结构"显现"了多少，而不是与参考基准竞争。
- **对齐值 X 用 C0 也比 L 少 0.044。** 原因是 scale 已经单独先传，X 的分布把"大 scale 的块里等级偏小"这一关系编进了取值本身。所以跨块变换的显现度以 X 为基准，块内变换以 L 为基准；同时都给出相对码值视图的数字。

### 指标口径

- **显现度** = 变换输入视图的原始码长 − 变换后码长（含边信息），分 C0、C1 两个编码器，单位 bit/权重。
  - 输入视图：块内变换为 L，跨块变换为 X，码值类方法为码值视图。
  - 排序类方法（C1 转置、C2 空间填充曲线、C4 BWT）以按行一维顺序编码的原始数据为基准。
- **净收益** = 参考基准总码长 − 变换方案总码长。变换方案取 C0、C1 中较好的一个，加上与参考基准相同的 scale 流；D1 的 scale 位平面变体则替换 scale 流。
- **选参：** 每个方法、每组变体只按训练集上的码长选最好的参数，测试集只用来报告。
