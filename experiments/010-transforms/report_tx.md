# 010 补充：变换全集实验（TX）

规格见 [docs/010-变换全集实验.md](../../docs/010-变换全集实验.md)。代码在 `tx/`，结果在 `results/tx/`，用时记录在 `results/tx/timing.md`。010、011 的已有结果没有改动。

## 阶段 0：基础设施

### 数据

- **主样本：** 010 的 48 个矩阵。训练/选参集为每层前两个专家（24 个矩阵），测试集为每层后两个专家（24 个，即 011 的 T1）。泛化检查用 011 的 T2（24 个）。
- **跨专家样本**（阶段 2 用）：第 0、13、26、39 层，每层用固定种子（`default_rng([20261119, 30, 层])`）从主样本以外的专家中取 16 个；前 8 个选参，后 8 个报告。

### 两种视图（`tx/txcore.py`）

- **码值视图：** R10（±0 合并）之后的 15 个符号。
- **数值视图：**
  - 块内等级 L：E2M1 值乘 2，取值为 −12…12 的整数。
  - 跨块对齐值 X：L × 2^(本块 scale 指数 − 矩阵最小指数)。实测最大绝对值为 3072，用 int64 存储，不会溢出。
- **往返检查：** 码值 → L → 码值、X → L 两条路径，在全部 72 个矩阵（训练、测试、T2）上逐位一致。

### 两个评价编码器

两个编码器都用自适应计数的闭式码长，可按顺序解码，不生成实际码流。

- **C0（零阶）：** 不用上下文。
  - 符号数据：自适应多元分布，每个符号先验计数为 1/2。
  - 整数数据：拆成位长类别（0 表示零）、符号位、尾数位。符号位以类别为上下文；尾数前 3 位以类别、位置和已出现的高位为上下文。这与 008 中音频、图像链（`increment.eg_bits`）的二值化方式相同。
- **C1（上下文）：** 在 C0 的基础上加入两个因果邻居。
  - 二维数据：左邻和上邻。
  - 一维序列：前两个值。
  - 整数数据用邻居的位长类别作上下文；符号位另加邻居的符号；尾数前 3 位另加邻居类别。符号数据直接用两个邻居的符号作上下文。
- **合成数据检查**（`results/tx/synthetic_stage0.json`，全部通过）：
  - 独立同分布的符号和整数：C0 与熵之差小于 0.01 bit/值。
  - 以 0.8 的概率复制左邻的符号：C1 为 1.126 bit/值，理论条件熵为 1.100。
  - 二维平滑尺度场上的整数：C1 比 C0 少 0.31 bit/值。

### 参考基准（实测，`results/tx/reference.json`）

参考基准是 008 链式模型加上 011 的 R9c（奇数等级个数、非零个数、最大等级三项计数上下文，每矩阵 1 个开关位），总码长包括 scale 流。

| | T1（测试集） | T2 |
|---|---:|---:|
| 008 链式总码长 | 3.65638 | 3.67437 |
| R9c 再省 | 0.05076 | 0.05313 |
| **参考基准总码长** | **3.60562** | **3.62124** |
| 其中 scale 流 | 0.03078 | 0.02793 |
| 其中码值部分 | 3.57483 | 3.59332 |

单位都是 bit/权重。T1 码值部分为 3.6255 − 0.0508 = 3.5748，与规格给的参考值一致。

### 原始数据的 C0、C1 码长（测试集，bit/权重，不含 scale 流）

| 视图 | C0 | C1 |
|---|---:|---:|
| 码值，二维 | 3.7750 | 3.7507 |
| 码值，按行一维 | 3.7750 | 3.7280 |
| 块内等级 L，二维 | 3.7750 | 3.7557 |
| 块内等级 L，按行一维 | 3.7750 | 3.7394 |
| 跨块对齐值 X，二维 | 3.7308 | 3.7181 |

- C1 比参考基准的码值部分多 0.15–0.18 bit/权重。因此用 C0、C1 编码的变换方案，净收益几乎必然为负。这两个编码器的作用是衡量变换本身让结构"显现"了多少，而不是与参考基准竞争。
- **对齐值 X 用 C0 也比 L 少 0.044。** 原因是 scale 已经单独先传，X 的分布把"大 scale 的块里等级偏小"这一关系编进了取值本身。所以跨块变换的显现度以 X 为基准，块内变换以 L 为基准；同时都给出相对码值视图的数字。

### 指标口径

- **显现度** = 变换输入视图的原始码长 − 变换后码长（含边信息），分 C0、C1 两个编码器，单位 bit/权重。
  - 输入视图：块内变换为 L，跨块变换为 X，码值类方法为码值视图。
  - 排序类方法（C1 转置、C2 空间填充曲线、C4 BWT）以按行一维顺序编码的原始数据为基准。
- **净收益** = 参考基准总码长 − 变换方案总码长。变换方案取 C0、C1 中较好的一个，加上与参考基准相同的 scale 流；D1 的 scale 位平面变体则替换 scale 流。
- **选参：** 每个方法、每组变体只按训练集上的码长选最好的参数，测试集只用来报告。

## 阶段 1：局部变换（A1–A5、B1–B5、C1、C2、D1）

代码：`tx/tx_local.py`（变换）、`tx/synth_tx_local.py`（合成检查）、`tx/tx_run.py`（运行与汇总）。结果：`results/tx/stage1/`。
163 个变体 × 48 个矩阵全部跑完，测试集上每个矩阵的往返检查全部通过（码值或数值逐位一致）。所有变体的结果见 [report_tx_variants.md](report_tx_variants.md)。

### 实现要点与对规格的偏差

- **A1 WHT：** 用整数和差（S 变换）蝶形逐级实现全 Hadamard（每级对和、差两路都继续变换），码值逐位可逆；随机符号用固定种子，不计边信息。
- **A2 DCT、A3 DFT、A5 重叠变换：** 没有实现整数 DCT、整数 FFT 和 JPEG XR 式整数重叠变换，都按规格允许的“近似 + 残差”做：
  - 正交实数变换后按步长 q 量化，解码端用 float64 重算近似值并取整，残差精确编码。
  - q 从 {0.5, 1, 2, 4, 8} 中在训练集上选（A5 为 {1, 2, 4, 8}）。
  - A5 是 Tran 等（2003）的时域前置滤波重叠变换：在每个 32 元块边界两侧各 M 个值上做正交前置滤波（M = 4、8，即重叠 8、16），再做块内 DCT-32。
- **A4 DWT：** Haar（S 变换）、CDF 5/3（JPEG 2000 无损模式）、CDF 9/7（提升系数逐步取整，省略最后的缩放）。方向有块内、整行、整列、二维（Mallat 分解），层数 1–5。
- **B4、B5：** SZ3 式层级插值（线性、三次）。
  - B5 只做了二维层级插值，没有做 MGARD 式多层网格（MGARD 需要按 L2 投影修正，实现代价大）。最接近它的是 A4 的二维 CDF 5/3。
- **B2：** 对“±0 合并后的 4 bit 编号”做异或，伙伴为 w1 ← w3、w2 ← w1 转置。w3 没有伙伴，不计入伙伴变体的平均。
- **C1、C2：** 改变编码顺序后，按一维序列用 C1（前两个值作上下文）编码，基准是原始数据按行一维编码。
  - 变体包括：按列（整体转置）；块列序（块内仍按原块编码，块与块按列排列）；z 序和希尔伯特曲线，分别以 32 元块和以码值为单元。
  - 二维的 C1（左、上邻居）对转置不敏感，所以不用它比较顺序。
- **D1：** 拆成零标志、符号、幅度三条流，C1 的上下文只用本字段的邻居；幅度再拆成 3 个位平面；scale 按 8 个位平面拆分。
  - scale 位平面变体只替换 scale 流，与参考的 scale 流比较，不参加码值变体的选参。

### 合成数据检查

`results/tx/synthetic_stage1.json`，49 项全部通过。

- **V-a（独立同分布的 FP4 式等级）：** 所有变换的显现度都 ≤ 0。排序类为 0，D1 字段拆分为 +0.006（低于 0.01 的阈值）。
- **V-b：** 每种变换在它针对的结构上显现度明显为正，例如：
  - 平滑二维场：WHT、DCT、DWT、插值、Lorenzo 为 +0.8 到 +4.4 bit/值。
  - 正弦叠加：DFT 为 +5.8。
  - 以 0.9 概率复制左邻：异或为 +1.9。
  - 只沿列相关的数据：按列顺序为 +2.2，希尔伯特曲线为 +0.4。
- **两项检查的设计说明：**
  - 随机符号 WHT 的 V-b 用“固定符号模式 × 平滑信号”，这是它能解开的结构。
  - 块列序、以块为单元的曲线只改变每块前两个码值的上下文，所以 V-b 阈值放宽到 0.005，实测为 +0.026 到 +0.116。

### 读法

- **没有任何局部变换让结构显现出来。** 163 个变体中显现度最高的是 D1 字段拆分（C1 +0.0012）和几种只改变块与块之间顺序的排列（±0.0000）。其余全部为负。
- **线性变换没有能量集中。**
  - 块内 DCT、DFT 和全行、全列 DFT 的编码增益都是 1.00：各频率系数的方差相同，与白噪声一致。
  - WHT（1.56）、Haar（1.25）的增益大于 1，但只来自和、差两路的取值范围不同（S 变换不是正交归一的），不代表能量集中。
  - 近似 + 残差类（A2、A3、A5）在训练集上总是选最大的量化步长，即越接近“不变换”越好。
- **差分、插值、回归类都更差。**
  - 相邻码值几乎独立，预测残差的熵大于原值的熵。块内一阶差分约多 0.6–0.8 bit/权重。
  - 块回归、异或是同类方法中最不差的（约 −0.2），因为它们把原值大部分原样留在残差或异或结果里。
- **跨块（对齐值 X）变体比块内变体差得多（约 −2 bit/权重）。** 原因是对齐后不同 scale 的块混在一起，变换系数继承了 scale 的跳变。
- **编码顺序：**
  - 按列、z 序、希尔伯特曲线（以码值为单元）比按行一维编码差 0.03–0.05，因为丢掉了同一块内前面的码值这一最强的上下文，与 010 T3 的结论一致。
  - 保留块内顺序的版本（块列序、以块为单元的曲线）与按行完全相同（差 < 0.0001）。块与块的邻接方向不携带可用的信息。
- **D1：**
  - 字段拆分（零标志、符号、幅度各用本字段邻居作上下文）只比联合编码多省 0.0012。
  - 幅度位平面拆分多花 0.11–0.13，因为拆开后丢掉了位之间的依赖。
  - scale 的位平面拆分与 008 的零阶 scale 码相同（差 0.0001）。
- **结论：** 局部变换在这批数据上都没有带来收益，全部在 011 探针的上限（链式模型之外约 0.07 bit/权重）之内，而且远低于它。阶段 1 的目的（确认收益很小）已经达到。
